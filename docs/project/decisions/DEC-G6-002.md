## 当前修订关系

本文件完整保留 Alibaba Cloud Model Studio 条件性基线的历史分析、应用和 Guard 证据。其 Chat Provider 路线已被 `DEC-G6-003` 修订为 DeepSeek API，当前权威 Chat Provider 不再是 Alibaba。Alibaba Embedding 也没有因本文件历史应用而自动成为当前选择，Embedding 继续等待独立决策。DEC-G6-001 的 no-call 边界仍有效。

## 1. 决策背景

DEC-G6-001 已应用“Provider 详情未决期间不发起真实外部请求”的 no-call 边界。用户随后完成 Alibaba Cloud Model Studio 方案的初选、正式二次确认，并授权“应用并同步 TECH-DEC-004-V2”。

本决策将 A 记录为 V1 的条件性 Provider 基线，但不把它解释为已启用的运行时服务。数据处理、保留、训练条款、用户账号资格和地区可用性仍需核验；在这些条件完成前，DEC-G6-001 的 no-call 保护继续有效。

## 2. 已应用的条件性基线

### 2.1 Provider 与模型

- Provider：Alibaba Cloud Model Studio。
- Chat Model：qwen3.8-flash。
- Embedding：text-embedding-v4。
- 候选地区：Singapore/International。
- 适配方式：通过本地后端 Provider Adapter；UI、Domain 和业务核心不直接依赖厂商 SDK。
- 运行时启用状态：DISABLED_UNTIL_GUARDS_VERIFIED。

### 2.2 强制保护条件

以下条件全部满足前，不得发起 Chat、Embedding 或文件内容请求：

1. Alibaba Model Studio API 数据处理、保留、训练用途、删除、分包方和适用地域条款已取得可核验官方资料；
2. 用户实际 Alibaba Cloud 账号、Model Studio 开通状态、付款资格和 Singapore/International 端点资格已确认；
3. 用户接受实际数据会如何离开本地的提示，尤其是完整知识库索引可能使大量解析文本切片分批发送到 Embedding 服务；
4. API Key 已由用户自行配置到本地后端安全配置中；本项目不读取、记录或验证 Key；
5. 实际成本保护策略完成后续技术设计。用户初选中的 USD 5/月仍标记为 PROPOSED_SOFT_BUDGET，不在本决策中当作已执行的计费上限；
6. 以上条件完成后重新执行 G6 Exit preflight，并由后续阶段定义失败、重试、取消、索引重建和 Provider 回退。

### 2.3 数据边界

- 原始文件二进制、备份文件、本地业务数据、向量索引和诊断日志默认留在用户设备，不因为本决策自动整体上传。
- 为完整建立 Embedding 索引，解析后的文本切片可能覆盖整个知识库并分批发送给外部 Embedding Provider；这与只发送问答命中片段不同，必须在产品提示中明确。
- Chat 请求只能携带当前任务必要的问题、检索命中片段和必要的有限会话上下文；不得默认上传全部历史或其它知识库数据。
- API Key 不进入前端、浏览器存储、仓库、备份正文、提示词或普通日志。
- 不提供云同步、远程备份、跨设备同步或远程业务服务器。

## 3. 成本边界

- 官方价格仍以评审文档访问时的价格页为参考，不构成报价或账单承诺。
- USD 5/月是用户初选中的软预算候选，当前状态为 PROPOSED，尚未作为运行时硬限制应用。
- 成本保护、Token 统计、去重、超预算停止和重试限制由 G8/G9 设计；在实现前不得宣称已具备预算阻断。

## 4. 影响与回退

- 文件解析等不依赖外部模型的本地工作可以继续设计；需要 Embedding 的索引在 guards 未满足时必须保持未完成/不可用状态。
- 自由对话、资料问答和学习陪练在运行时 Provider 未启用时不得伪装为生成成功；用户可见未配置或暂不可用状态留给 G8/G9 设计。
- Provider 条款、账号资格或区域核验失败时，回退到 DEC-G6-001 no-call，不自动切换供应商、不自动发送数据、不自动增加预算。
- Provider 或模型版本变化可能触发局部或全量 Embedding 重建；正式迁移和重建规则留 G8/G9。
- 本决策不改变 Approved PRD 业务范围，不代表 G6 完成，不授权代码、密钥、真实 API 或发布操作。
