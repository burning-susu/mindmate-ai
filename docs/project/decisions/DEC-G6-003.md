## 4. DeepSeek 官方资料核验摘要

本轮只读取公开官方 DeepSeek API 文档，没有调用 API、登录平台或读取 Key。

- Models & Pricing：`https://api-docs.deepseek.com/quick_start/pricing`。当前列出 `deepseek-flash` 与 `deepseek-v4-pro`；Flash 为 1M 上下文、最大输出 384K，支持 thinking、JSON、Tool Calls、Responses API 和 Anthropic API。
- Chat Completions：`https://api-docs.deepseek.com/api/create-chat-completion`。公开 `POST /chat/completions` 及 OpenAI 兼容请求结构。
- 流式输出：Chat Completions 的 `stream=true` 返回部分消息增量和 SSE 事件；`stream_options.include_usage` 可在最后一个 chunk 提供用量，项目断线恢复和正式流式协议仍留 G9。
- Thinking Mode：`https://api-docs.deepseek.com/guides/thinking_mode`。thinking 默认启用，默认 effort 为 high；支持启用/禁用和 reasoning effort；thinking 模式下部分采样参数不适用。
- JSON Output：`https://api-docs.deepseek.com/guides/json_mode`。支持 `response_format={"type":"json_object"}`，但官方提示可能出现空内容，需由后续实现处理。
- Tool Calls：`https://api-docs.deepseek.com/guides/tool_calls`。官方提供工具调用格式示例。
- Rate Limit & Isolation：`https://api-docs.deepseek.com/quick_start/rate_limit`。公开 Flash 并发限制为 2500；超限返回 HTTP 429；限制按账号计算。
- Pricing：峰时/非峰时以及缓存命中/未命中价格不同；费用从充值余额或赠送余额扣除，价格可调整。标价不等于本项目已执行的预算保护。

## 5. Secret 与本地架构边界

- 前端、浏览器存储和客户端日志不得持有 `DEEPSEEK_API_KEY`。
- 只有本地后端 Provider Adapter 可以从本机环境变量或未提交的 `.env`/系统 Secret 配置读取 Key。
- `.env`、`.env.local`、密钥文件和含敏感信息的日志必须由 `.gitignore` 排除；`.env.example` 只能保留空占位符。
- Key 缺失、配置无效、余额不足或 Guard 未通过时必须安全失败，Provider 保持禁用，不自动切换或自动充值。
- 模型 ID、Base URL、预算和限流参数通过配置层管理，不散落在业务模块。
- 本轮不创建、读取、验证、展示或测试任何 Key；DEC、Evidence、日志、截图和测试夹具不保存真实 Secret。
