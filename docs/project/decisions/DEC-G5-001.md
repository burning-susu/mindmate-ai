## 决策背景

V1 的原始文件、解析结果、业务数据和向量默认保存在用户本地，删除默认不可恢复，项目不需要云服务器。G5 评审发现，如果不确定备份和恢复责任，PRD 无法明确用户数据丢失边界和验收责任。

## 已应用决策

用户已完成影响复述、二次确认并授权应用方案 B：

- V1 提供轻量本地导出/备份和恢复能力；
- 不提供云同步、远程备份或跨设备同步；
- 备份和恢复仍发生在用户本地；
- 产品必须提示备份文件可能包含原始资料、会话和其他敏感内容；
- 具体备份格式、内容范围、加密、覆盖、索引重建和失败恢复规则留到 G6/G8/G10 确认。

## 产品影响

- V1 增加本地导出、选择备份位置、恢复确认、恢复失败提示和数据覆盖警告。
- 恢复后如果向量索引不能直接复用，系统需要支持重新解析、切片、Embedding 和索引。
- 备份文件和恢复过程需要纳入隐私、安全、测试和验收范围。
- 不改变本地单用户、无云服务器和外部 Provider 数据边界。

## 被拒方案

- 方案 A：不提供应用内备份/恢复；交付成本更低，但无法通过产品恢复本地资料。
- 方案 C：引入云备份；改变当前本地部署、隐私、成本和数据边界。

## 未决技术细节

- 备份是否包含原始文件、业务数据、会话、引用和向量索引；
- 备份格式、版本和完整性校验；
- 是否加密以及密钥由谁管理；
- 恢复时覆盖、合并还是创建新知识库；
- 部分恢复失败时的回滚和清理；
- 向量索引不可复用时的重建规则；
- 数据目录迁移、卸载和磁盘损坏提示。
