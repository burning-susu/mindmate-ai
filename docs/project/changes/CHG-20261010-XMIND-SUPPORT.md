# CHG-20261010-XMIND-SUPPORT

状态：`IMPLEMENTED_LOCAL`

日期：2026-10-10

## 来源与范围

用户明确要求支持 `.xmind` 文件。此变更将 XMind 加入既有本地文件管理、解析、搜索、知识库索引和详情预览流程，不改变应用的本地单用户定位或现有文件大小/批次限制。

## 变更对象

- `KEEP`：PDF、DOCX、PPTX、TXT、Markdown 的导入、解析、存储和预览行为；所有文件继续走托管副本、SHA-256 判重和持久解析任务。
- `ADD`：XMind 格式识别、MIME/签名校验、隔离解析器、JSON/XML 主题树提取、详情页预览、文件类型筛选和所有上传入口的扩展名支持；主题文本进入现有搜索和 RAG 索引。
- `REVALIDATE`：压缩包条目数、展开大小、压缩比、解析时间、内存和解析输出限制；覆盖新旧格式和伪装 ZIP 用例。
- `NO CHANGE`：数据库结构、文件导入 API 请求结构、Provider、Embedding、向量存储和真实外部服务调用。

## 行为与安全边界

1. 只识别 ZIP 根目录 `content.json` 或 `content.xml` 的 XMind 包；其余不符合结构的文件按伪装/无效格式拒绝。
2. 解析时只读取主题结构文件，不解压 ZIP 成员到文件系统，不执行或外发附件、脚本和链接。预览可按需读取固定路径 `Thumbnails/thumbnail.png`，用于显示 XMind 包自带的原版式缩略图；不读取其他图片或附件。
3. JSON 和旧版 XML 均在现有受限解析子进程中解析；沿用 ZIP 条目、展开体积、压缩比、解析超时、内存和输出限制，并增加重复 ZIP 条目、主题数/层级和主数据大小限制。
4. 文件详情优先显示经 XMind 应用保存的嵌入式 PNG 预览，受文件大小、PNG 签名及像素上限约束；缩略图缺失或无效时回退到工作表、根主题和子主题结构。解析出的主题文本可用于当前文件全文搜索与既有知识库索引。

## 原版式预览增量

- 新增只读 API `GET /api/v1/files/{file_id}/xmind-thumbnail`，直接以 `image/png` 返回包内缩略图，不进行格式重绘、不落盘，也不新增外部依赖。
- 图片不完整、缺失或超出上限时返回 `204`；前端自动回退到解析后的主题树。
- 前端提供打开原尺寸预览入口；其他文件类型和索引内容不变。

## 验收证据

后端文件管理契约覆盖 JSON/XML 成功路径、嵌入式缩略图响应、无缩略图回退和伪装 ZIP 拒绝；前端覆盖原版式预览、失败回退和上传选择。原版式增量验证见 `docs/test-reports/stage-87-xmind-native-thumbnail.md`。`IMPLEMENTED_LOCAL` 不等同合并、发布或完整 V1 阶段验收。
