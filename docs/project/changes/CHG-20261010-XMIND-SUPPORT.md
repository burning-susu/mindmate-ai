# CHG-20261010-XMIND-SUPPORT

状态：`IMPLEMENTED_LOCAL`

日期：2026-10-10

## 来源与范围

用户明确要求支持 `.xmind` 文件。此变更将 XMind 加入既有本地文件管理、解析、搜索、知识库索引和详情预览流程，不改变应用的本地单用户定位或现有文件大小/批次限制。

## 变更对象

- `KEEP`：PDF、DOCX、PPTX、TXT、Markdown 的导入、解析、存储和预览行为；所有文件继续走托管副本、SHA-256 判重和持久解析任务。
- `ADD`：XMind 格式识别、MIME/签名校验、隔离解析器、JSON/XML 主题树提取、详情页树形视图、文件类型筛选和所有上传入口的扩展名支持；主题文本进入现有搜索和 RAG 索引。
- `REVALIDATE`：压缩包条目数、展开大小、压缩比、解析时间、内存和解析输出限制；覆盖新旧格式和伪装 ZIP 用例。
- `NO CHANGE`：数据库结构、文件导入 API 请求结构、Provider、Embedding、向量存储和真实外部服务调用。

## 行为与安全边界

1. 只识别 ZIP 根目录 `content.json` 或 `content.xml` 的 XMind 包；其余不符合结构的文件按伪装/无效格式拒绝。
2. 只读取主题结构文件，不解压 ZIP 成员到文件系统，不展示、执行或外发附件、脚本、图片和链接。
3. JSON 和旧版 XML 均在现有受限解析子进程中解析；沿用 ZIP 条目、展开体积、压缩比、解析超时、内存和输出限制，并增加重复 ZIP 条目、主题数/层级和主数据大小限制。
4. 文件详情展示工作表、根主题和子主题层级；解析出的主题文本可用于当前文件全文搜索与既有知识库索引。

## 验收证据

后端文件管理契约覆盖 JSON/XML 成功路径与伪装 ZIP 拒绝；前端覆盖主题树及上传选择；Pyright、Ruff、compileall、Vitest、typecheck、lint、build 结果记录于第八十五批测试报告和进度文档。`IMPLEMENTED_LOCAL` 不等同合并、发布或完整 V1 阶段验收。
