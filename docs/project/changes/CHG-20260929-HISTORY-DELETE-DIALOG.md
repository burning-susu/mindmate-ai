# CHG-20260929-HISTORY-DELETE-DIALOG

状态：`IMPLEMENTED_LOCAL`

日期：2026-09-29

## 来源与用户决定

第七十六批用户指令确认：对话历史和学习历史的“移入回收站”“永久删除”共用居中模态；显示对象名称与操作影响；永久删除说明不可恢复且只删除对应历史记录，不删除源文件或知识库；取消、关闭按钮和 Escape 关闭弹窗；永久删除不再要求输入确认词，以醒目的危险按钮作为明确确认。

用户回报第七十五批人工卡六项均已完成且未发现功能问题；指出的唯一体验问题是第六项历史删除确认界面。该回报记录为用户口述，不包含逐项对象 ID、URL、Network 次数或可读取截图路径，不代表代理亲测。

## 基线与范围

- `docs/project/requirements/v1/08_历史记录与后台任务.md` 保持历史对象及来源数据边界；永久删除历史不得删除关联文件或知识库。
- `docs/project/requirements/v1/14_UI设计映射与前端规范.md` 要求永久删除使用危险对话框，明确对象、影响和不可撤销性，并让主按钮描述具体动作。
- 本变更只覆盖对话历史与学习历史的软删除、永久删除确认交互。文件、文件夹、知识库、备份恢复、整库清理和任务取消交互不在范围内。

## 变更对象

- `KEEP`：现有历史删除/恢复 API、`row_version` 乐观锁、服务端 `confirmed=true`、错误或结果未知后刷新列表、历史来源与后台任务语义。
- `REVALIDATE`：对话历史和学习历史的确认层、键盘焦点、忙碌态、重复提交保护、取消和错误提示测试。
- `ADD`：共享居中模态组件、行为回归、阶段 76 验收报告和人工卡修订说明。
- `REMOVE`：仅删除历史永久删除确认词输入及依赖该输入的前端状态和文案。

## API 与数据边界

当前服务端永久删除 API 的 `confirmed` 布尔字段及应用服务校验为必填。该字段不要求用户输入确认词；前端在用户点击模态中的具体危险操作后继续发送 `confirmed=true`。本变更保留它和既有 `expected_version`，不改 API/OpenAPI、数据库、持久化或后端逻辑。

历史删除不会自动取消文件或知识库后台任务。历史操作和任务状态在人工卡中分别验证。
