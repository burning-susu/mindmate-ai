## 4. 范围审计

已明确并可继承：

- V1 目标：将个人文件转化为可查询、可追溯、可练习的个人知识库。
- 目标用户：学生和备考者、自学者、初级开发者、知识工作者。
- 核心闭环：创建知识库 → 上传文件 → 解析和索引 → 资料问答和真实引用 → 逐题陪练 → 历史会话恢复。
- V1 核心功能：知识库管理、文本型 PDF/DOCX/Markdown/TXT 文件处理、自由对话、资料问答、引用、基础陪练、历史会话。
- V1 排除：多智能体、工作流编排、团队权限、OCR、联网搜索、复杂学习算法、语音陪练、移动端完整适配、独立错题本和设置页。
- 使用边界：本地单用户 MVP；原始文件、业务数据和向量默认本地保存；必要文本可以发送到外部模型/Embedding Provider，不是完全离线。

必须在 G4 统一：

- 产品说明书将基础设置列在“首版包含”中；HIGH-04 已确认设置页延后。G4 PRD 必须以 DEC-BOOTSTRAP-001 为当前决策约束，并保留来源差异追踪。
- “五个一级页面”与详细页面清单的关系尚未裁决，见 G3-BLOCKER-001。

## 6. 业务规则审计

已明确：

- 支持文本型 PDF、DOCX、Markdown、TXT。
- V1 默认单文件 20MB、单次最多 5 个文件，OCR 关闭。
- 文件状态和消息/陪练状态集合已给出。
- 同库同名和内容指纹重复文件需要提示。
- 删除知识库、文件和会话需要二次确认；删除文件后历史引用失效但历史消息可保留。
- 资料问答必须限定知识库，资料不足时明确拒答。
- 陪练一次一题，等待用户回答后点评；用户决定继续或结束。
- userId 保留，服务层必须执行资源归属校验。
- 数据默认本地保存，必要文本才发送外部 Provider。

需要补齐为 PRD 规则：

- 上传取消后已创建任务的终止、取消或继续策略。
- 解析/索引失败的自动重试次数和人工重试入口。
- 删除后是否允许从本地备份恢复。
- 删除后重新导入同一文件的指纹和历史引用行为。
- Provider 错误类型与用户消息、重试、人工配置动作的映射。

## 7. 页面和交互范围审计

当前可识别的 V1 页面或模块：

- 首页或工作台：快捷入口、最近会话、最近文件、基础统计和空状态。
- AI 对话页：三种模式、消息区、输入区、引用侧栏和生成状态。
- 知识库列表：创建、搜索、排序和打开知识库。
- 知识库详情：文件列表、上传入口和处理概览。
- 文件详情：基础信息、摘要、标签、解析文本、限定文件问答/陪练。
- 历史会话：搜索、继续、重命名和删除。
- 上传、解析、索引、生成中、失败、空和错误状态。

设置页根据 HIGH-04 不属于 V1；独立错题本不属于 V1。

- 分类：BLOCKER / CONFLICT

- 来源依据：SRC-002 第 7 节和表 8；SRC-003 第 5 章、附录 A/C；CONFLICT-04；DEC-BOOTSTRAP-001/HIGH-04。
- 当前已知事实：核心功能页面已识别；设置页和独立错题本已明确延后；一级入口和嵌套路由未确认。
- 方案 A：五个一级页面壳，知识库详情和文件详情作为知识库/文件模块嵌套页面，设置页排除。
- 方案 B：详细页面分别作为独立路由，设置页排除；在 PRD 中废弃“五个一级页面”表述。
- 方案 C：保留设置页以匹配产品说明书表 8；与 HIGH-04 冲突，不建议。

- 推荐方案及理由：A，同时保留已确认 V1 核心闭环和“五个一级页面”约束，不重新引入设置页。

- 状态：APPLIED_DEC-G3-001。

### G3-MAJOR-001 外部 Provider 失败语义不完整

- 分类：MAJOR
- 问题：资料覆盖网络中断、模型超时和一般重试，但没有统一定义 Provider 不可用、限流/配额、Key 错误、Embedding 失败和是否允许降级。

- 推荐方案及理由：A 符合当前单 Provider Adapter 和 V1 范围；具体错误码和状态在 G8/G9 确认。
