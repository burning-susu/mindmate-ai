## 审计目的

本文件是 G2 的预审，不是 G3 PRD 准入结论。它检查当前来源和决策是否足以进入下一步审计，并保留尚未收敛的业务和契约问题。

## 已具备内容

- 产品目标：把个人文件转化为可查询、可追溯、可练习的知识库。
- 核心用户和场景：个人学习者、知识工作者，围绕文件、问答、引用和陪练。
- 核心范围：知识库、文件、资料问答、引用、陪练、历史会话。
- 非目标：多智能体、工作流、团队权限、OCR、联网搜索、复杂学习算法等。
- 文件状态：上传、解析、索引、可用、失败。
- 消息和陪练状态：需求文档已提供候选状态集合。
- 数据归属方向：userId 和服务层资源归属校验已确认。
- 安全方向：密钥服务端、本地数据默认保存、提示注入隔离和文件校验已确认。
- 测试范围：单元、API/契约、核心 E2E、基础安全、轻量性能基线已确认。

## 尚不满足 G3 的内容

| 编号 | 检查项 | 当前结果 | 影响 |
|---|---|---|---|
| ALIGN-01 | 页面树和一级导航 | 部分明确，存在五页与多层页面表述差异 | 需要在 G3/G5.5 收敛 UI 范围 |
| ALIGN-02 | 需求是否可全部转为 Given/When/Then | 现有文档有验收场景，但不是每个 FR 都已结构化 | G3 需要补齐可测试表达 |
| ALIGN-03 | API/数据/鉴权契约 | 只确认方向，路径、字段、流式、上传和鉴权 TBD | 不得进入依赖契约的实现 |
| ALIGN-04 | Provider 和隐私条款 | Provider 名称、地域、条款 TBD | G6 需要技术和隐私复核 |
| ALIGN-05 | NFR 验收阈值和环境 | 有初始目标，缺少测试环境和证据格式 | G3/G10 需要确定验证方式 |
| ALIGN-06 | 版本和负责人 | V1.0 资料存在，但负责人、目标日期和正式批准人 TBD | 影响 Approved 和计划门禁 |

## 结论

- 当前 G2 来源和决策基线：满足退出条件。
- 当前 G3 PRD 准入：不启动。
- 原因：Workflow 已确认，但页面树、逐条验收表达、API/数据契约、Provider 隐私约束和正式责任人仍有待收敛。
- 这不是 G2 失败；G3 入口门禁已通过，本轮只停在 G3 尚未执行。

G3 已在 Workflow 确认后单独执行；本文件不替代 G3 审计结论。
