# 02 信息架构与页面清单

## 1. 文档目的

本文档确定 MindMate AI V1 的全局导航、页面层级、页面职责、主要跳转关系和全局辅助界面。

本文档不描述页面内部的所有字段和操作。首页、文件、知识库、AI 对话和学习陪练的详细交互将在后续模块文档中展开。

## 2. 已确认决策

| 决策项 | 最终选择 | 结果 |
| --- | --- | --- |
| 全局导航 | 左侧边栏 | 桌面端保持稳定的模块入口和当前位置识别 |
| 一级入口 | 五个核心入口 | 首页、学习、AI 对话、知识库、文件 |
| 历史记录 | 独立二级页面 | 统一查看对话历史和学习历史，不占用核心一级入口 |
| 后台任务 | 全局状态按钮＋任务抽屉 | 用户在任意页面都能查看处理进度，不增加一级页面 |

## 3. 信息架构原则

### 3.1 学习优先

学习是一级导航的第二项，仅次于首页。知识库、文件和 AI 对话为学习提供资料和交互基础。

### 3.2 五个核心入口稳定

V1 一级导航固定为：首页、学习、AI 对话、知识库、文件。开发过程中不得把历史、任务、设置等辅助功能扩展为新的一级入口。

### 3.3 列表与详情分层

文件、知识库、历史等模块采用列表页进入详情页的结构。详情页属于对应模块，不在左侧边栏重复出现。

### 3.4 当前任务随时可见

解析、切片、Embedding 和索引可能持续较长时间。全局顶部区域显示任务状态入口，点击后打开任务抽屉。

### 3.5 历史统一管理

AI 对话历史和学习陪练历史在“历史记录”页面集中展示，并保留从 AI 对话和学习模块进入对应历史的快捷入口。

### 3.6 减少页面跳转

来源引用、文件选择、知识库选择和任务状态优先使用抽屉、弹窗或侧面板，避免用户频繁离开当前学习或对话页面。

## 4. 全局应用框架

~~~mermaid
flowchart LR
    S["左侧边栏"] --> M["主内容区"]
    M --> H["页面顶部栏"]
    M --> C["页面内容"]
    H --> T["任务状态入口"]
    T --> D["任务抽屉"]
~~~

### 4.1 左侧边栏

边栏包含：

- 产品名称或 Logo；
- 首页；
- 学习；
- AI 对话；
- 知识库；
- 文件；
- 辅助入口：历史记录；
- 边栏折叠按钮。

边栏需要明确显示当前所在模块。折叠后显示图标，并通过悬浮提示展示名称。

V1 不在边栏放置用户头像、团队切换、订阅升级或管理员入口。

### 4.2 页面顶部栏

顶部栏根据页面显示：

- 当前页面标题；
- 必要的面包屑；
- 页面级主要操作；
- 全局任务状态按钮；
- 必要的帮助提示。

V1 不设置独立“通知中心”。处理完成、失败等消息通过页面反馈、Toast 和任务抽屉表达。

### 4.3 主内容区

主内容区承载列表、详情、聊天或学习界面。不同模块可以使用各自布局，但必须保留统一的边栏和顶部栏。

### 4.4 全局覆盖层

全局可使用任务抽屉、文件选择弹窗、知识库选择弹窗、引用来源抽屉、删除确认弹窗、离开确认弹窗、全局 Toast 和错误详情弹窗。

## 6. 页面清单

### PAGE-HOME：首页 / 工作台

**建议路径：** /

**页面职责：**

- 汇总最近使用内容；
- 展示学习优先入口；
- 展示正在处理或失败的任务；
- 提供快速上传、快速提问和开始学习；
- 帮助用户从上一次活动继续。

**主要区域：**欢迎与快捷操作、继续学习、最近知识库、最近文件、最近对话、任务状态摘要。

**主要去向：**开始学习、对话工作区、知识库详情、文件详情、任务抽屉和历史详情。

### PAGE-LEARNING：学习首页

**建议路径：** /learning

**页面职责：**

- 启动新的学习陪练；
- 选择知识库或文件；
- 设置学习主题和目标；
- 查看最近学习记录；
- 继续未完成或最近的学习。

**主要去向：**开始学习配置、学习会话、学习总结和学习历史。

### PAGE-LEARNING-SETUP：开始学习

**建议路径：** /learning/new

**页面职责：**

- 选择学习资料；
- 输入学习主题或目标；
- 选择后续确定的陪练参数；
- 检查资料是否可用；
- 创建学习会话。

如果配置内容较少，可以作为学习首页中的步骤区或弹窗实现；如果内容较多，则使用独立页面。最终形式在学习陪练详细需求中确定。

### PAGE-LEARNING-SESSION：学习会话

**建议路径：** /learning/session/:id

**页面职责：**

- 展示当前问题；
- 接收用户回答；
- 展示 AI 点评、解释和引用；
- 允许重试、继续下一题和结束学习；
- 展示当前学习进度和必要上下文。

学习会话是 V1 的核心页面，应减少不必要跳转。

### PAGE-LEARNING-SUMMARY：学习总结

**建议路径：** /learning/session/:id/summary

**页面职责：**

- 展示本次学习概览；
- 展示已练习内容；
- 展示理解较好和需要复习的内容；
- 展示资料引用；
- 允许重新学习或返回学习首页。

### PAGE-CHAT：AI 对话工作区

**建议路径：** /chat

**页面职责：**

- 新建和切换对话；
- 普通 AI 对话；
- 选择知识库或文件作为问答范围；
- 展示流式回答；
- 展示引用来源；
- 停止生成、重新生成和继续追问；
- 进入对话历史。

对话列表可以作为页面内部的次级侧栏，不能取代全局导航边栏。

### PAGE-KB-LIST：知识库列表

**建议路径：** /knowledge-bases

**页面职责：**

- 展示全部知识库；
- 创建知识库；
- 搜索、筛选和排序；
- 展示文件数量、索引状态和最近使用时间；
- 进入知识库详情；
- 删除知识库。

### PAGE-KB-DETAIL：知识库详情

**建议路径：** /knowledge-bases/:id

**页面职责：**

- 展示知识库信息；
- 管理知识库中的文件；
- 显示解析和索引状态；
- 添加或移除文件；
- 重试失败任务或重建索引；
- 从当前知识库开始问答；
- 从当前知识库开始学习。

### PAGE-FILE-LIST：文件列表

**建议路径：** /files

**页面职责：**

- 上传或导入文件；
- 管理文件夹；
- 管理标签；
- 搜索、筛选和排序；
- 批量选择和批量操作；
- 展示解析、索引和关联状态；
- 进入文件详情。

页面内部可以包含文件夹树、筛选栏和文件列表，但不得把文件夹设计为新的一级页面。

### PAGE-FILE-DETAIL：文件详情

**建议路径：** /files/:id

**页面职责：**

- 展示文件基本信息；
- 展示解析状态和错误；
- 展示摘要和标签；
- 展示所属文件夹和关联知识库；
- 预览或打开支持的内容；
- 重新处理；
- 从当前文件开始问答或学习；
- 删除文件。

### PAGE-HISTORY：历史记录

**建议路径：** /history

**页面职责：**

- 统一查看对话历史和学习历史；
- 搜索、筛选和排序；
- 查看会话摘要、时间和使用资料；
- 恢复对话或查看学习总结；
- 删除历史记录；
- 提示关联文件或知识库已经删除、失效或发生变化。

**页面结构：**对话历史标签页、学习历史标签页。

历史记录是独立二级页面，可从边栏辅助区域、AI 对话页和学习页进入，但不属于五个核心一级入口。

## 7. 全局辅助界面

### UI-TASK-DRAWER：任务抽屉

**打开方式：**

- 顶部栏任务状态按钮；
- 首页任务摘要；
- 文件或知识库中的处理状态入口。

**职责：**

- 展示排队、处理中、成功、失败和已取消任务；
- 显示任务类型和关联对象；
- 显示进度；
- 展示失败原因；
- 提供重试、取消或查看对象入口；
- 清理已完成记录。

抽屉关闭后任务继续执行。用户切换页面不能导致任务中断。

### UI-SOURCE-DRAWER：引用来源抽屉

点击 AI 回答或学习点评中的引用标记后打开，展示来源文件、引用片段、页码或章节等定位信息，并提供文件详情或预览入口。

### UI-FILE-PICKER：文件选择器

用于向知识库添加文件、选择文件问答和选择文件学习。支持搜索、文件夹、标签、处理状态和多选。

### UI-KB-PICKER：知识库选择器

用于 AI 对话和学习陪练选择资料范围，显示知识库名称、文件数量、索引状态和最近使用时间。

### UI-CONFIRM-DIALOG：确认弹窗

用于删除文件、删除知识库、删除会话、取消任务、离开未提交回答和结束学习等不可逆或影响较大的产品操作。

产品操作的删除确认属于安全交互，不等于项目决策流程中的二次确认。

## 8. 导航与跳转规则

### 8.1 默认入口

应用启动后默认进入首页。

如果需要首次配置外部模型 Key，V1 通过启动指引或本地配置说明解决，不因此增加“设置”一级页面。

### 8.2 跨模块快捷入口

允许以下跨模块快捷跳转：

- 文件详情 → 基于此文件提问；
- 文件详情 → 基于此文件开始学习；
- 知识库详情 → 基于此知识库提问；
- 知识库详情 → 基于此知识库开始学习；
- 对话引用 → 引用来源抽屉 → 文件详情；
- 学习点评引用 → 引用来源抽屉 → 文件详情；
- 首页最近记录 → 对应详情；
- 历史记录 → 恢复对话或查看学习总结。

### 8.3 返回规则

- 从列表进入详情后，返回时保留搜索、筛选、排序和滚动位置；
- 从引用来源进入文件详情后，应能够返回原对话或学习会话；
- 学习会话进行中离开时，根据是否存在未保存回答决定是否提示；
- 关闭任务抽屉不影响当前页面和任务执行。

### 8.4 页面刷新与恢复

- 列表页刷新后重新读取本地数据并保留可序列化的筛选条件；
- 对话页刷新后恢复当前会话；
- 学习会话页刷新后恢复已保存进度；
- 详情对象不存在时展示“已删除或不可用”状态，并提供返回入口。

## 9. 页面通用状态

| 状态 | 说明 |
| --- | --- |
| Initial | 页面首次进入，尚未产生数据 |
| Loading | 正在读取本地数据 |
| Empty | 请求成功，但当前没有内容 |
| Ready | 正常展示内容 |
| Partial | 部分区域成功、部分区域失败 |
| Error | 页面关键数据读取失败 |
| Offline Provider | 本地应用可用，但外部 AI Provider 不可用 |
| Object Missing | 文件、知识库或会话已删除 |

空状态必须提供下一步操作，而不是只显示“暂无数据”。

## 13. 验收标准

### IA-AC-01

应用启动后进入首页，左侧边栏显示五个核心入口。

### IA-AC-02

用户可以从边栏进入首页、学习、AI 对话、知识库和文件，并明确看到当前选中项。

### IA-AC-03

用户可以从边栏辅助区域、学习页或对话页进入统一历史记录页面。

### IA-AC-04

用户在任意主要页面均可通过顶部状态按钮打开任务抽屉。

### IA-AC-05

从文件或知识库详情可以直接发起对话或学习，并自动携带当前资料范围。

### IA-AC-06

点击 AI 回答或学习点评中的引用，不离开当前页面即可查看来源摘要。

### IA-AC-07

从列表进入详情再返回时，列表的查询条件和位置得到合理保留。

### IA-AC-08

页面对象不存在、数据为空或加载失败时，显示对应状态和可执行的下一步。

## 14. 本部分冻结结论

- V1 采用左侧边栏；
- 一级导航固定为首页、学习、AI 对话、知识库、文件；
- 学习入口排序高于 AI 对话、知识库和文件；
- 历史记录使用独立二级页面；
- 后台任务使用全局状态入口和任务抽屉；
- 文件、知识库和学习采用列表/入口到详情或会话的层级；
- 引用、资料选择和任务查看优先使用抽屉或弹窗；
- V1 不增加设置、通知、用户中心和管理后台页面。

后续可以细化页面内部结构，但不得无记录地改变上述信息架构。
