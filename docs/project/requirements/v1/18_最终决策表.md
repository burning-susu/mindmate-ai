## 17. 实施期允许调参但不重开决策

以下可依据测试在同一方案内调整：

- Chunk 的精确字符数和重叠；
- FTS/向量候选数、RRF 常量和证据阈值；
- ONNX 批大小和任务轮询间隔；
- UI 间距、断点和组件文件拆分；
- 超时、有限重试次数和日志滚动大小；
- Prompt 文案、温度和输出 Token 上限；
- SQLite 索引和安全 PRAGMA 的性能值。

调整必须有测试证据，不得改变隐私、范围、引用、严格拒答或数据模型语义。

## 18. 外部事实复核清单

这些不是用户二次确认，而是开发/发布内部检查：

- DeepSeek Base URL、模型别名、价格、上下文、限流与条款；
- bge-small-zh-v1.5 模型 revision、许可证和哈希；
- Windows、Web Runtime 和 Python 依赖支持周期；
- sqlite-vec、ONNX Runtime 与 PyInstaller 的 Windows 兼容；
- 依赖漏洞、许可证和代码签名状态。

复核失败只有在改变最终方案时才触发正式变更。

## 19. 推荐方案选择汇总

本轮由助手代为采用的关键推荐项：

1. Windows 11 x64 正式支持，Windows 10 仅尽力兼容；
2. React 19＋TypeScript＋Vite 前端；
3. Python 3.12＋FastAPI 本地后端；
4. SQLite＋FTS5＋sqlite-vec；
5. bge-small-zh-v1.5 采用 ONNX Runtime CPU；
6. 本地规则混合重排，不加入第二个模型；
7. SQLite 持久 Worker，不引入 Redis/Celery；
8. PyInstaller one-folder＋Inno Setup；
9. V1 使用系统浏览器，不提前引入 Electron/Tauri；
10. 模型首次按需下载，不塞入安装包；
11. 技术 Spike 先验证 Windows 向量、ONNX、凭据和打包；
12. V1 不扩展 OCR、本地 LLM、同步、多人和工具调用。
