# 08 历史记录与后台任务

## 1. 文档目的

本文档定义 MindMate AI V1 的对话历史、学习历史、历史搜索与恢复、全局任务抽屉、后台任务队列、任务进度、取消、重试、应用重启恢复、数据失效提示和任务记录清理规则。

本模块整合此前分散在首页、文件、知识库、AI 对话和学习陪练中的历史与任务要求。各业务模块不得自行实现不一致的任务状态、重试规则或历史恢复逻辑。

## 2. 本轮开发基线

本部分没有需要阻断后续设计的高风险产品决策，直接采用适合单用户本地应用的默认基线。

| 项目 | V1 基线 |
| --- | --- |
| 历史入口 | 一个统一历史页面，包含“对话历史”和“学习历史”两个标签页 |
| 历史保存 | 默认长期保存在本地，直到用户删除 |
| 历史删除 | 进入回收站，保留 30 天 |
| 任务入口 | 全局任务抽屉，不增加新的一级导航 |
| 应用关闭 | 本地任务停止运行；保存检查点，重启后安全恢复 |
| 任务并发 | 由资源类型控制；默认最多同时运行 2 个重任务 |
| 任务记录 | 成功和取消保留 7 天；失败、阻塞和中断保留 30 天 |
| AI 交互请求 | 聊天流式回答、题目生成和点评不进入任务抽屉 |
| 通知 | 应用内状态、徽标和 Toast；V1 不做系统通知和云端推送 |

并发数量属于可配置技术参数。低性能设备可以降低为 1，不改变产品行为。

## 3. 模块目标

### 3.1 历史记录目标

帮助用户：

- 找回以前的对话；
- 继续未完成的学习；
- 查看已完成的学习总结；
- 搜索历史内容；
- 识别关联资料是否仍可用；
- 删除、恢复和永久清理历史记录。

### 3.2 后台任务目标

帮助用户：

- 了解哪些文件正在处理；
- 了解知识库索引进度；
- 离开当前页面后仍可查看任务；
- 取消允许取消的长任务；
- 对失败任务执行安全重试；
- 应用重启后恢复未完成任务；
- 清理不再需要的任务记录。

## 4. 边界定义

### 4.1 历史记录

历史记录属于用户内容，包括：

- AI 对话及其消息、回答版本和引用；
- 学习会话、题目、作答、点评、总结和复习关系。

历史记录不会因为任务记录过期而消失。

### 4.2 后台任务

后台任务是具有以下特征的本地处理：

- 预计耗时较长；
- 用户可以离开发起页面；
- 需要持久化进度；
- 可能被取消、重试或在重启后恢复；
- 处理结果会改变文件、知识库或本地索引状态。

### 4.3 不进入任务抽屉的操作

以下属于交互请求或短操作，V1 不作为全局后台任务展示：

- AI 对话流式回答；
- AI 回答重新生成；
- 学习计划的普通生成请求；
- 单道学习题生成；
- 单次学习点评；
- 页面数据加载；
- 标题修改；
- 标签修改；
- 普通列表搜索；
- 小型数据库写入。

这些操作仍需要自身的请求状态、错误处理和幂等控制，但不占用任务抽屉。

如果后续测试证明某类 AI 操作经常超过可接受时长，可以通过版本规划升级为持久任务，V1 不预先扩大范围。

## 5. 历史记录页面

### 5.1 页面路径

建议路径：/history

历史记录是辅助二级页面，可从以下位置进入：

- 左侧边栏辅助区域；
- AI 对话页；
- 学习首页；
- 首页最近对话；
- 首页继续学习；
- 全局搜索结果。

历史记录不属于五个核心一级导航入口。

### 5.2 页面结构

页面包含：

- 页面标题；
- 搜索框；
- “对话历史”标签页；
- “学习历史”标签页；
- 当前标签页筛选器；
- 排序入口；
- 历史列表；
- 空状态；
- 加载、错误和来源失效状态。

切换标签页时保留各自的搜索词、筛选条件和滚动位置，直到用户离开页面或主动清除。

### 5.3 默认标签页

- 从 AI 对话进入时打开对话历史；
- 从学习模块进入时打开学习历史；
- 从边栏直接进入时恢复上次使用的标签页；
- 没有上次状态时默认打开对话历史。

## 6. 对话历史

### 6.1 列表字段

每条对话记录至少显示：

- 标题；
- 普通聊天或知识库聊天标识；
- 最近资料范围摘要；
- 最后一条用户问题或回答摘要；
- 消息数量；
- 创建时间；
- 最后更新时间；
- 来源状态；
- 会话状态。

不得在列表加载时读取全部消息正文。

### 6.2 会话状态

| 状态 | 含义 |
| --- | --- |
| ACTIVE | 正常可继续 |
| INTERRUPTED | 上次生成异常中断 |
| SOURCE_INVALID | 当前知识范围失效，历史可看但不能直接继续知识库聊天 |
| IN_TRASH | 已进入回收站 |

普通聊天不因知识库删除进入 SOURCE_INVALID。

### 6.3 打开行为

- ACTIVE：进入原对话并定位到上次阅读位置或末尾；
- INTERRUPTED：进入原对话，显示中断消息及继续或重新生成入口；
- SOURCE_INVALID：进入原对话，先显示范围问题，历史仍可阅读；
- 已完成搜索定位：进入会话后滚动到命中消息，并短暂高亮。

### 6.4 来源摘要

知识库聊天显示：

- 当前或最近使用的知识库名称；
- 或文件范围中的文件数量与主要文件名；
- 是否存在回收站、永久删除或索引失效来源。

历史回答保存各自的资料范围快照，列表的“最近资料范围”不替代消息级快照。

## 7. 学习历史

### 7.1 列表字段

每条学习记录至少显示：

- 学习主题；
- 学习目标类型；
- 资料范围摘要；
- 会话状态；
- 完成题数和目标题量；
- 正确、部分正确和错误摘要；
- 最近学习时间；
- 下一次复习日期；
- 结束原因；
- 来源状态。

### 7.2 学习状态

| 状态 | 打开行为 |
| --- | --- |
| PREPARING | 进入准备状态页 |
| READY | 进入会话并开始 |
| IN_PROGRESS | 继续当前题 |
| PAUSED | 恢复学习 |
| INTERRUPTED | 恢复未完成步骤 |
| COMPLETED | 打开学习总结 |
| SOURCE_INVALID | 查看既有记录与失效说明 |
| FAILED | 查看失败详情和可用操作 |
| IN_TRASH | 仅在回收站查看 |

### 7.3 未完成会话

列表优先显示明确的“继续学习”按钮。继续前重新检查：

- 资料范围；
- 文件与知识库状态；
- 索引版本；
- 当前题与草稿；
- 未完成点评。

### 7.4 已完成会话

点击进入学习总结。用户可以查看完整题目记录、薄弱点和复习安排。

已完成会话不会因为复习到期重新变为进行中；到期复习将创建新的复习会话。

## 8. 历史分组、排序与分页

### 8.1 默认排序

对话历史和学习历史默认按最后活动时间倒序。

### 8.2 时间分组

可以使用以下视觉分组：

- 今天；
- 最近 7 天；
- 最近 30 天；
- 更早。

分组只是展示，不改变数据排序。

### 8.3 可选排序

V1 支持：

- 最近更新；
- 最早创建；
- 标题排序。

学习历史可以额外按下一次复习时间排序。

### 8.4 加载

- 首次只加载一页；
- 滚动或分页加载后续记录；
- 不一次读取全部消息、题目和点评；
- 切换标签页不应重新加载已缓存的当前页；
- 数据变化后只更新受影响项。

## 9. 历史搜索

### 9.1 搜索范围

对话历史搜索：

- 会话标题；
- 用户消息正文；
- AI 回答正文。

学习历史搜索：

- 学习主题；
- 学习目标；
- 题干；
- 用户答案；
- AI 点评；
- 学习总结；
- 知识点名称。

### 9.2 搜索原则

- 搜索索引保存在本地；
- 输入防抖；
- 显示命中摘要；
- 高亮关键词；
- 点击定位到具体消息、题目或总结区域；
- 默认排除回收站；
- 不搜索内部 Prompt、API Key、完整错误堆栈和隐藏参考答案字段。

### 9.3 搜索结果

一个历史对象有多处命中时：

- 列表以历史对象为主项；
- 显示最相关的 1～3 个命中片段；
- 允许展开查看更多命中；
- 不把同一会话拆成大量重复列表项。

### 9.4 无结果

显示：

- 当前搜索词；
- 当前筛选条件；
- 清除筛选；
- 修改关键词建议。

不得在无结果时自动搜索回收站或外部服务。

## 10. 历史筛选

### 10.1 对话筛选

支持：

- 全部；
- 普通聊天；
- 知识库聊天；
- 可继续；
- 来源失效；
- 异常中断。

### 10.2 学习筛选

支持：

- 全部；
- 进行中；
- 已暂停；
- 已完成；
- 今日需复习；
- 来源失效；
- 失败或中断。

### 10.3 时间筛选

支持：

- 今天；
- 最近 7 天；
- 最近 30 天；
- 自定义日期范围。

### 10.4 筛选组合

搜索词、类型、状态和时间可以组合。页面显示已启用条件，并提供一键清除。

V1 不保存多个命名筛选视图。

## 11. 历史对象操作

### 11.1 对话操作

支持：

- 打开；
- 继续；
- 编辑标题；
- 复制标题；
- 删除；
- 查看来源状态。

V1 不提供公开分享链接和批量导出。

### 11.2 学习记录操作

支持：

- 继续学习；
- 查看总结；
- 查看完整记录；
- 复习薄弱点；
- 删除；
- 查看来源状态。

### 11.3 删除

删除前显示：

- 对象名称；
- 将进入 30 天回收站；
- 不会删除文件和知识库；
- 对话删除会移除正常历史与搜索；
- 学习记录删除会暂时移除其复习项。

确认后执行软删除。

V1 默认支持单条删除。批量删除历史不作为必须功能，避免增加误删风险。

## 12. 历史恢复与永久删除

### 12.1 恢复

从回收站恢复后：

- 回到原标签页；
- 恢复标题、消息、题目、作答、点评、总结和引用；
- 恢复搜索索引；
- 恢复学习复习项；
- 重新检查所有关联来源；
- 不自动重新生成 AI 内容。

### 12.2 资料失效

历史恢复不等于资料恢复。关联文件或知识库仍在回收站、已永久删除或索引失效时，历史对象标记 SOURCE_INVALID。

### 12.3 永久删除

永久删除按照 06 和 07 文档清理对象所属数据。

永久删除历史记录不得：

- 删除关联文件；
- 删除知识库；
- 删除共享索引；
- 影响其他对话；
- 影响其他学习会话；
- 清理仍被其他对象引用的掌握记录。

## 13. 来源失效状态

### 13.1 失效类型

| 类型 | 含义 |
| --- | --- |
| SOURCE_IN_TRASH | 来源在回收站 |
| SOURCE_DELETED | 来源已永久删除 |
| INDEX_UNAVAILABLE | 索引缺失或损坏 |
| INDEX_VERSION_MISMATCH | 索引版本不兼容 |
| KB_MEMBERSHIP_CHANGED | 知识库成员关系发生变化 |
| PARTIAL_SOURCE | 部分来源仍可用 |

### 13.2 对话处理

- 历史消息始终可查看；
- 历史引用显示当前来源状态；
- 新问题发送前要求修复范围；
- 不静默忽略无效文件；
- 不静默切换为普通聊天。

### 13.3 学习处理

- 已有题目和点评可查看；
- 进行中会话不能继续生成新题；
- 提供恢复来源、重建索引、结束会话或基于新范围开始；
- 不在原会话中直接替换资料范围。

### 13.4 重新可用

来源恢复后执行校验：

- 对象 ID；
- 文件内容版本；
- 知识库成员关系；
- 索引版本；
- 引用定位。

只有满足原会话一致性要求时才恢复 ACTIVE 或可继续状态。

## 14. 全局任务抽屉

### 14.1 打开方式

- 顶部栏任务状态按钮；
- 首页任务状态摘要；
- 文件处理状态；
- 知识库索引状态；
- 失败提示中的“查看任务”；
- 任务完成 Toast。

### 14.2 抽屉结构

从右侧打开，保留当前页面上下文。包含：

- 状态摘要；
- 进行中任务；
- 排队任务；
- 需要处理的失败或阻塞任务；
- 最近完成任务；
- 筛选；
- 清理已完成记录；
- 关闭按钮。

Esc 可以关闭。同一时间只显示一个主抽屉。

### 14.3 摘要

显示：

- 正在执行数量；
- 排队数量；
- 失败或阻塞数量；
- 最近一项任务；
- 可计算时的总体进度。

没有活动、失败和最近完成任务时，抽屉显示空状态。

### 14.4 任务卡片

至少显示：

- 任务名称；
- 任务类型；
- 关联文件或知识库；
- 当前状态；
- 当前步骤；
- 进度；
- 创建时间；
- 开始时间或等待原因；
- 取消、重试或查看对象操作。

失败详情默认折叠，不在列表直接显示底层堆栈。

## 15. 后台任务类型

### 15.1 文件任务

- FILE_IMPORT：复制文件到应用目录；
- FILE_PARSE：解析正文与结构；
- FULLTEXT_INDEX：建立全文搜索索引；
- FILE_REPROCESS：重新解析文件；
- FILE_BATCH_OPERATION：支持的批量文件操作；
- FILE_PURGE：永久删除后的文件清理。

### 15.2 知识库和 RAG 任务

- CHUNK_BUILD：生成切片；
- EMBEDDING_BUILD：生成 Embedding；
- VECTOR_INDEX_BUILD：建立向量索引；
- FILE_REINDEX：单文件重建；
- KB_REINDEX：整库重建；
- INDEX_CLEANUP：清理不再引用的索引数据。

### 15.3 维护任务

- SEARCH_INDEX_REBUILD：重建本地搜索索引；
- TRASH_PURGE：清理到期回收站数据；
- ORPHAN_CLEANUP：清理已确认无引用的临时文件；
- DATA_MIGRATION：应用升级需要的数据迁移。

备份与恢复如果进入 V1，在 09_数据模型与本地存储.md 中确定后，可新增 BACKUP_CREATE 和 BACKUP_RESTORE。

### 15.4 交互请求

CHAT_GENERATE、LEARNING_QUESTION 和 LEARNING_FEEDBACK 不属于上述任务队列，使用独立请求状态。

## 16. 父任务与子任务

### 16.1 批量导入

一次导入多个文件创建一个父任务，每个文件创建独立子任务。

父任务展示：

- 总文件数；
- 成功数；
- 失败数；
- 处理中数量；
- 总体进度。

一个文件失败不阻止其他文件。

### 16.2 处理流水线

单个文件可以由以下阶段组成：

~~~mermaid
flowchart TD
    A["复制文件"] --> B["解析正文"]
    B --> C["全文索引"]
    C --> D{"加入知识库？"}
    D -->|是| E["切片与 Embedding"]
    E --> F["向量索引"]
    D -->|否| G["文件可用"]
~~~

阶段可以作为一个任务的检查点，也可以作为关联子任务。技术实现必须保证界面看到统一的处理流程。

### 16.3 父任务状态

- 全部子任务成功：SUCCEEDED；
- 部分成功、部分失败：PARTIAL；
- 全部失败：FAILED；
- 用户取消剩余项：CANCELLED 或 PARTIAL；
- 仍有子任务运行：RUNNING；
- 全部未开始：QUEUED。

## 17. 任务状态

| 状态 | 含义 |
| --- | --- |
| CREATED | 已创建但尚未进入调度 |
| QUEUED | 等待执行 |
| RUNNING | 正在执行 |
| BLOCKED | 等待依赖、配置或用户处理 |
| PAUSE_REQUESTED | 已请求在安全点暂停 |
| PAUSED | 已暂停，可继续 |
| CANCELLING | 正在安全取消 |
| CANCELLED | 已取消 |
| SUCCEEDED | 成功完成 |
| PARTIAL | 批任务部分成功 |
| FAILED | 执行失败 |
| INTERRUPTED | 应用退出或异常导致中断 |

状态变化必须持久化并记录时间。

## 18. 任务进度

### 18.1 可计算进度

当总工作量已知时显示：

- 百分比；
- 已完成数量和总数量；
- 当前步骤；
- 预计剩余时间，仅在有可靠估算时显示。

### 18.2 不可计算进度

总量未知时：

- 显示明确步骤；
- 显示已经处理的数量；
- 使用不确定进度样式；
- 不伪造连续增长的百分比；
- 不长期停留在 99% 而没有说明。

### 18.3 进度更新

- 进度节流写入，避免频繁数据库更新；
- 关键阶段立即写入；
- 页面刷新后恢复最后持久化进度；
- 父任务进度按子任务工作量加权，不只按子任务数量平均；
- 失败子任务计入已处理数量，但不计为成功。

## 19. 任务优先级

### 19.1 优先级

V1 使用：

- HIGH：用户正在等待的必要处理；
- NORMAL：常规导入、解析和新增索引；
- LOW：整库重建、清理和维护。

### 19.2 初始排序

同一优先级默认先进先出。

初始优先规则：

1. 用户明确重试且正在查看的对象；
2. 新导入文件的必要处理；
3. 新加入知识库的索引；
4. 批量重建；
5. 清理与维护。

### 19.3 防止饿死

低优先级任务等待过久时逐步提升调度权重，但不超过正在等待的用户关键任务。

V1 不提供用户手动拖拽调整队列顺序。

## 20. 资源与并发

### 20.1 资源类型

任务标记主要资源：

- DISK_IO；
- CPU；
- MEMORY；
- NETWORK；
- MODEL_RUNTIME；
- DATABASE_EXCLUSIVE。

### 20.2 默认并发

适合普通个人电脑的初始建议：

- 总重任务最多 2 个；
- 文档解析最多同时 2 个文件；
- Embedding 或向量索引最多 1 个；
- 数据迁移或独占维护最多 1 个；
- 永久清理最多 1 个。

实际数值在技术架构阶段通过配置和性能测试确定。

### 20.3 资源保护

- 内存不足时降低并发；
- 数据库独占任务阻止冲突写入；
- 同一文件不能同时解析和重建；
- 同一知识库不能同时执行两个整库重建；
- 交互请求优先保持界面可用；
- 任务不能占满全部 CPU 导致应用无法操作。

## 21. 依赖与阻塞

任务可以依赖其他任务，例如：

- 全文索引依赖解析成功；
- Embedding 依赖切片成功；
- 向量索引依赖 Embedding；
- 知识库可用状态依赖至少一个文件索引完成；
- 清理依赖引用计数确认。

依赖未满足时使用 BLOCKED，而不是反复失败重试。

任务卡片需要显示简化原因，例如：

- 等待文件解析；
- 等待 API Key；
- 等待索引重建；
- 目标对象在回收站；
- 磁盘空间不足。

## 22. 取消任务

### 22.1 可取消

- QUEUED 任务可以立即取消；
- RUNNING 任务在安全检查点取消；
- 批量父任务可以取消尚未开始的子任务；
- 已完成的子任务不回滚；
- 数据迁移的关键提交阶段可能不可取消。

### 22.2 取消确认

取消正在运行或批量任务前显示：

- 已完成部分会保留还是回滚；
- 未开始部分将停止；
- 原文件是否保留；
- 是否可以稍后重试。

取消排队且没有副作用的单项任务可以使用简化确认。

### 22.3 安全取消

取消必须：

- 停止后续阶段；
- 保留原始文件副本；
- 不发布不完整索引；
- 清理无引用临时产物；
- 保存检查点和取消原因；
- 更新关联对象状态；
- 不把取消显示为失败。

## 23. 任务重试

### 23.1 可重试条件

以下失败可重试：

- 临时文件锁；
- 网络或 Provider 暂时不可达；
- 限流；
- 可恢复解析错误；
- 临时数据库忙；
- 应用异常中断；
- 用户修复配置后的阻塞。

以下情况需要先修复，不应盲目自动重试：

- 文件损坏；
- 不支持格式；
- API Key 无效；
- 磁盘空间不足；
- 目标对象已永久删除；
- 索引配置不兼容；
- 数据库迁移失败。

### 23.2 重试起点

重试从最近的安全检查点开始：

- 文件已复制则不重复复制；
- 解析成功则不重复解析；
- 已完成且版本一致的 Embedding 可复用；
- 未正式发布的损坏索引先清理；
- 成功子任务不重复执行。

### 23.3 幂等

每项业务操作具有幂等键。重复点击、页面刷新、网络重试和应用重启不得创建重复任务或重复发布索引。

### 23.4 自动重试

V1 只对明确的短暂错误执行有限自动重试：

- 初始建议最多 2 次；
- 使用递增等待；
- 显示正在重试和次数；
- 达到上限后变为 FAILED；
- 鉴权、余额、格式和磁盘问题不自动重试。

用户手动重试创建新的运行 Attempt，但保留原任务关系与历史。

## 24. 应用关闭与重启

### 24.1 运行边界

MindMate AI V1 没有独立服务器。应用完全关闭后，本地后台任务不会继续执行。

不得向用户暗示关闭电脑或退出应用后任务仍在运行。

### 24.2 正常退出

应用退出时：

- 停止接受新的后台任务；
- 对运行任务请求安全暂停；
- 保存当前检查点；
- 原子写入任务状态；
- 未能及时暂停的任务标记 INTERRUPTED；
- 不强制发布半成品。

### 24.3 异常退出

启动时扫描 RUNNING、CANCELLING 和 PAUSE_REQUESTED：

- 判断是否存在完整产物；
- 清理未提交临时产物；
- 标记 INTERRUPTED；
- 检查幂等键与检查点；
- 自动恢复安全任务或等待用户处理。

### 24.4 自动恢复

可以自动重新入队：

- 文件解析；
- 全文索引；
- 切片；
- Embedding；
- 向量索引；
- 普通清理。

以下操作启动后先要求用户处理或执行完整校验：

- 数据迁移；
- 备份恢复；
- 永久删除关键阶段；
- 无法确认产物一致性的重建。

### 24.5 恢复提示

启动后如果存在中断任务：

- 任务按钮显示状态；
- 首页任务摘要显示恢复数量；
- 自动恢复任务显示“已从上次进度继续”；
- 需要操作的任务显示明确入口；
- 不使用大量 Toast 逐条打扰用户。

## 25. 关联对象状态同步

### 25.1 文件

文件任务状态需要同步到：

- 文件列表；
- 文件详情；
- 首页最近文件；
- 文件选择器；
- 任务抽屉。

### 25.2 知识库

索引任务状态需要同步到：

- 知识库列表；
- 知识库详情；
- 首页最近知识库；
- 知识库选择器；
- AI 对话资料范围；
- 学习资料范围；
- 任务抽屉。

### 25.3 同一事实来源

页面状态必须来源于同一个持久任务和业务对象状态，不允许每个页面自己猜测。

例如，任务 FAILED 后，知识库不能仍显示 PREPARING；任务重试后，所有入口都应更新。

## 26. 对象进入回收站

### 26.1 文件

文件进入回收站后：

- 取消尚未开始的相关任务；
- 运行任务在安全点停止；
- 不再创建新索引任务；
- 历史任务保留并标记对象在回收站；
- 恢复文件后可以重新处理。

### 26.2 知识库

知识库进入回收站后：

- 停止未开始的知识库任务；
- 不影响原始文件的独立处理；
- 整库重建安全停止；
- 共享文件级 Embedding 不立即删除；
- 恢复后检查索引版本。

### 26.3 永久删除

永久删除自身可以形成清理任务。清理任务必须：

- 使用明确对象 ID；
- 检查引用；
- 分阶段提交；
- 可报告部分失败；
- 不误删共享数据。

## 27. 任务完成通知

### 27.1 成功

- 当前应用可见时显示简短 Toast；
- 任务按钮更新；
- 关联对象页面更新；
- 批量任务显示成功与失败数量；
- 不要求用户确认。

### 27.2 失败

- 任务按钮显示失败徽标；
- 首页任务摘要保留；
- 当前相关页面显示局部错误；
- Toast 给出“查看详情”；
- 不展示敏感底层信息。

### 27.3 取消

- 显示任务已取消；
- 说明已完成部分是否保留；
- 提供重新处理入口；
- 取消记录不使用错误徽标。

### 27.4 V1 通知边界

V1 不提供：

- 操作系统通知；
- 邮件；
- 短信；
- 云端推送；
- 应用关闭后的远程提醒。

## 29. 任务记录保留

### 29.1 默认期限

- QUEUED、RUNNING、BLOCKED、PAUSED：任务存在期间持续保留；
- SUCCEEDED、CANCELLED：完成后保留 7 天；
- PARTIAL、FAILED、INTERRUPTED：结束后保留 30 天；
- 数据迁移记录：至少保留当前应用版本生命周期。

期限从任务进入终态时计算。

### 29.2 清理记录

用户可以在任务抽屉：

- 清除已成功任务；
- 清除已取消任务；
- 清除已处理失败记录；
- 一键清除符合条件的完成记录。

活动任务不可清除，只能在规则允许时取消。

### 29.3 清理边界

清理任务记录只删除运行记录和不再需要的诊断信息，不删除：

- 文件；
- 知识库；
- 索引成品；
- 对话；
- 学习记录；
- 用户数据。

## 33. 状态流

### 33.1 任务主状态流

~~~mermaid
stateDiagram-v2
    [*] --> QUEUED
    QUEUED --> RUNNING
    RUNNING --> SUCCEEDED
    RUNNING --> FAILED
    RUNNING --> INTERRUPTED
    RUNNING --> CANCELLING
    CANCELLING --> CANCELLED
    FAILED --> QUEUED: 重试
    INTERRUPTED --> QUEUED: 恢复
    QUEUED --> CANCELLED
~~~

BLOCKED 和 PAUSED 可以在满足条件或用户继续后回到 QUEUED。

### 33.2 历史删除流

~~~mermaid
stateDiagram-v2
    ACTIVE --> IN_TRASH: 删除
    IN_TRASH --> ACTIVE: 恢复
    IN_TRASH --> PURGED: 到期或永久删除
~~~

恢复后可能因为来源问题进入 SOURCE_INVALID，而不是直接 ACTIVE。

## 34. 空状态与异常状态

### 34.1 没有历史

- 对话历史显示“开始第一次对话”；
- 学习历史显示“开始第一次学习”；
- 提供对应主要按钮；
- 不显示无意义筛选。

### 34.2 搜索无结果

- 保留搜索词；
- 提供清除筛选；
- 不自动跳转到全局搜索。

### 34.3 没有任务

- 显示“当前没有处理任务”；
- 任务入口保留但无警示徽标；
- 首页任务摘要可以隐藏。

### 34.4 任务系统异常

- 业务页面仍可读取已有数据；
- 暂停创建新的长任务；
- 显示任务调度不可用；
- 提供重启应用或查看诊断入口；
- 不把任务直接丢失或全部标记成功。

## 35. 性能要求

### 35.1 历史

- 历史列表使用分页或虚拟滚动；
- 搜索使用本地索引；
- 列表不加载完整正文；
- 命中定位按需加载目标附近内容；
- 删除或恢复只更新相关项。

### 35.2 任务

- 进度更新需要节流；
- 任务调度不能阻塞界面线程；
- 大文件处理使用流式读取；
- 后台任务限制 CPU、内存和并发；
- 应用启动恢复不扫描全部文件正文；
- 任务抽屉只加载最近记录，旧记录按需加载。

## 36. 一致性要求

- 任务状态与业务对象状态使用明确事务边界；
- 任务成功前不发布不完整索引；
- 任务失败后不把文件标记 READY；
- 页面显示状态以持久数据为准；
- 同一幂等键只有一个活动任务；
- 父任务汇总必须与子任务一致；
- 历史软删除同步更新搜索索引；
- 历史恢复同步恢复搜索索引；
- 回收站清理不会误删其他对象引用的数据；
- 重试不会重复生成业务成品。

## 37. 安全要求

- 任务参数使用内部对象 ID，不直接信任前端文件路径；
- 文件路径需要规范化和目录边界校验；
- 清理任务不得使用未经验证的宽泛路径；
- 永久删除前重新解析明确目标；
- 不执行文档中的脚本或指令；
- 任务错误不泄露密钥、Prompt 和正文；
- 任务日志保存在本地；
- 前端不能伪造任务成功；
- 数据迁移与恢复需要完整性校验；
- 清理共享索引前检查引用。

## 38. V1 不做

- 独立任务管理一级页面；
- 远程任务服务器；
- 应用关闭后继续在云端运行；
- 多用户任务隔离；
- 跨设备任务同步；
- 用户拖拽队列排序；
- 复杂任务依赖图界面；
- 系统级通知；
- 邮件、短信和推送；
- 历史公开分享；
- 历史批量导出；
- 历史命名筛选视图；
- AI 交互请求全部进入任务抽屉；
- 无限期保存所有任务日志。

## 39. 验收标准

### HISTORY-AC-01

历史记录页面包含对话历史和学习历史两个标签页，并根据进入来源打开对应标签。

### HISTORY-AC-02

对话列表显示标题、模式、资料摘要、更新时间和来源状态，不需要加载全部消息。

### HISTORY-AC-03

学习列表显示主题、状态、题目进度、下次复习和来源状态。

### HISTORY-AC-04

搜索可以命中对话消息和学习题目、答案、点评或总结，并定位到具体位置。

### HISTORY-AC-05

搜索与类型、状态和时间筛选可以组合，默认不包含回收站。

### HISTORY-AC-06

未完成学习从历史页恢复当前题、草稿和进度；已完成学习打开总结。

### HISTORY-AC-07

来源失效时历史仍可查看，但系统不会静默忽略无效来源或自动切换模式。

### HISTORY-AC-08

删除历史后进入 30 天回收站；恢复不自动重新生成 AI 内容。

### HISTORY-AC-09

永久删除对话或学习记录不删除关联文件、知识库和仍被其他对象使用的数据。

### TASK-AC-01

文件解析、Embedding、索引和批量处理进入后台任务，离开发起页面后仍可在任务抽屉查看。

### TASK-AC-02

任务抽屉展示排队、运行、阻塞、失败、部分成功、完成和取消状态。

### TASK-AC-03

任务展示当前步骤；总量已知时展示真实进度，总量未知时不伪造百分比。

### TASK-AC-04

批量导入的单个文件失败不阻止其他文件，父任务正确显示成功与失败数量。

### TASK-AC-05

默认重任务并发不超过 2，Embedding 或向量索引默认同时只运行 1 个，且可配置降低。

### TASK-AC-06

排队任务可以立即取消，运行任务在安全点取消，不发布半成品索引。

### TASK-AC-07

重试从安全检查点开始，不重复复制文件、不重复成功阶段，也不创建重复业务成品。

### TASK-AC-08

短暂错误最多自动重试 2 次；鉴权、余额、文件损坏和磁盘空间错误不会盲目自动重试。

### TASK-AC-09

应用完全关闭后任务不再运行；重启后能够识别中断任务并从安全检查点恢复。

### TASK-AC-10

数据迁移、备份恢复或无法确认一致性的关键任务不会未经校验自动恢复。

### TASK-AC-11

同一任务状态同步显示在文件、知识库、选择器、首页和任务抽屉中。

### TASK-AC-12

目标进入回收站后取消未开始任务，并让运行任务安全停止。

### TASK-AC-13

成功或取消的任务记录默认保留 7 天，失败、部分失败和中断记录默认保留 30 天。

### TASK-AC-14

清理任务记录不会删除文件、知识库、索引成品、对话或学习记录。

### TASK-AC-15

聊天流式回答、单题生成和学习点评不进入全局任务抽屉，但各自保留请求状态和错误恢复。

### TASK-AC-16

任务日志和错误详情不包含 API Key、完整 Prompt、完整正文或未脱敏敏感响应。

## 40. 本部分冻结结论

- 使用一个统一历史页面，包含对话和学习两个标签页；
- 历史记录默认长期本地保存，直到用户删除；
- 历史删除进入 30 天回收站；
- 对话历史可定位到消息，学习历史可定位到题目、点评或总结；
- 历史页明确显示来源失效；
- 恢复历史不自动重新生成 AI 内容；
- 长时间文件和索引处理进入全局任务抽屉；
- AI 流式回答、题目生成和点评不进入任务抽屉；
- 批量任务使用父子任务，单项失败不阻止其他项；
- 任务具有持久状态、检查点、幂等键、依赖和运行 Attempt；
- 默认最多同时运行 2 个重任务；
- Embedding 或向量索引默认同时运行 1 个；
- 取消发生在安全点，不发布半成品；
- 重试从最近安全检查点开始；
- 临时错误最多自动重试 2 次；
- 应用完全关闭后任务不继续运行；
- 应用重启后扫描中断任务并安全恢复；
- 任务状态在所有相关页面使用同一事实来源；
- 成功和取消任务记录默认保留 7 天；
- 失败、部分失败和中断任务记录默认保留 30 天；
- 清理任务记录不删除业务数据；
- V1 只提供应用内任务提示；
- V1 不做远程任务服务器、系统通知和复杂队列管理界面。
