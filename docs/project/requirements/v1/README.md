# MindMate AI V1 需求规格文档包

## 项目说明

MindMate AI 是面向个人用户、在 Windows 本地运行的 AI 知识学习助手。V1 将文件整理、知识库/RAG、可溯源 AI 对话和逐题学习陪练连接为完整闭环。

## 文档状态

- 版本：V1.0 需求基线
- 状态：已冻结，可进入代码开发
- 适用项目：`burning-susu/mindmate-ai`
- 数据原则：本地优先；AI 生成时仅向 DeepSeek 发送必要上下文

## Codex 使用方式

将压缩包放入或解压到项目可读取的位置，然后给 Codex 以下指令：

~~~text
读取 00、18、16，并按 16_Codex开发任务书.md 从仓库审计开始连续开发。
不要重新发起已冻结决策；需要取舍的普通实现细节采用推荐最佳实践。
每个阶段完成后运行测试并建立独立 Git 提交；只有命中停止条件时才询问我。
~~~

Codex 应先检查现有仓库和未提交修改，不得为了套用目录而覆盖用户已有代码。

## 已冻结的核心技术

- React 19＋TypeScript＋Vite；
- Python 3.12＋FastAPI；
- SQLite＋FTS5＋sqlite-vec；
- 本地 ONNX `BAAI/bge-small-zh-v1.5` Embedding；
- DeepSeek API `deepseek-flash`；
- SQLite 持久后台任务；
- PyInstaller one-folder＋Inno Setup；
- Windows 11 x64 正式支持；
- 无云服务器、无 Docker 必需依赖、无 Redis、无自动模型切换。

## 变更规则

普通实现细节由 Codex 自主完成。只有需求冲突、冻结技术被 Windows Spike 证明不可行、新增外部账号/费用/权限、存在安全风险或需要破坏性操作时，才暂停询问用户。
