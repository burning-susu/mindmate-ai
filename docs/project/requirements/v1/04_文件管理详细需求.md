# 04 文件管理详细需求

## 1. 文档目的

本文档定义 MindMate AI V1 文件导入、存储、分类、标签、搜索、解析、预览、重复检测、批量操作、删除恢复和知识库关联规则。

文件管理服务于知识库问答和学习陪练，不发展为复杂网盘。

## 2. 已确认决策

| 决策项 | 最终选择 |
| --- | --- |
| 支持格式 | PDF、DOCX、PPTX、TXT、Markdown |
| 保存方式 | 导入后复制到应用管理目录 |
| 重复文件 | 按内容哈希识别，提示复用现有文件或另存独立记录 |
| 分类方式 | 文件夹＋标签 |
| 删除规则 | 进入回收站保留 30 天 |

## 3. 文件概念

V1 区分三个概念：

- 原始来源文件：用户从电脑中选择的文件；
- 应用管理文件：导入后复制到 MindMate AI 数据目录的文件；
- 文件记录：数据库中保存的名称、类型、哈希、目录、标签、处理状态等信息。

用户导入完成后，应用不再依赖来源路径。用户移动或删除原始来源文件，不影响应用中的文件、知识库和历史记录。

## 4. 支持的文件类型

### 4.1 PDF

支持：

- 可提取文本的普通 PDF；
- 按页提取文本；
- 保留页码用于引用；
- PDF 原文预览；
- 标题和基础元数据提取。

V1 不包含 OCR。扫描版 PDF 如果无法提取有效文字，应显示“未检测到可解析文本”，保留文件预览，但不能直接进入索引完成状态。

### 4.2 DOCX

支持提取：

- 标题；
- 段落；
- 列表；
- 表格中的可读文本；
- 页眉页脚中的必要文本；
- 文档基础属性。

引用优先使用章节、标题和段落定位；无法稳定取得页码时不得伪造页码。

### 4.3 PPTX

支持提取：

- 幻灯片标题；
- 文本框内容；
- 表格文本；
- 演讲者备注中可读取的文字；
- 幻灯片编号。

图片中的文字不做 OCR。引用使用幻灯片编号定位。

### 4.4 TXT

支持：

- UTF-8；
- 常见文本编码识别；
- 编码无法识别时允许用户重新选择编码；
- 按段落和行号定位。

二进制文件伪装成 TXT 时必须拒绝解析。

### 4.5 Markdown

支持：

- 标题层级；
- 正文；
- 列表；
- 引用；
- 代码块；
- 表格文本；
- 链接文字；
- 按标题或行号定位。

V1 不自动下载 Markdown 中引用的网络图片或远程资源。

### 4.6 V1 不支持

- DOC；
- XLS、XLSX；
- CSV；
- HTML；
- 图片 OCR；
- 音频和视频；
- 压缩包；
- EPUB；
- 在线网页抓取。

上传不支持类型时，应在复制前拒绝，并说明当前支持的格式。

## 5. 文件限制

V1 默认限制：

| 项目 | 默认值 |
| --- | --- |
| 单文件最大体积 | 50 MB |
| 单次最多选择 | 20 个文件 |
| 单次导入总量 | 500 MB |
| 文件夹最大层级 | 5 层 |
| 单个文件最多标签 | 10 个 |
| 标签名称长度 | 1～30 个字符 |
| 文件夹名称长度 | 1～100 个字符 |
| 文件显示名称长度 | 1～255 个字符 |

这些值后续可以成为本地配置，但 V1 不为此增加独立设置页面。

超过限制时，在复制前阻止对应文件，并允许继续导入其他合格文件。

## 6. 导入方式

V1 支持：

- 点击“导入文件”后通过系统文件选择器多选；
- 将文件拖放到文件页面的导入区域；
- 从首页快捷操作进入导入；
- 从知识库添加文件时导入新文件。

V1 不要求一次导入整个操作系统目录。用户可以多选文件，然后在应用中移动到目标文件夹。

## 7. 导入流程

~~~mermaid
flowchart TD
    A["选择文件"] --> B["校验类型与大小"]
    B --> C["计算内容哈希"]
    C --> D{"是否重复"}
    D -->|否| E["复制到应用目录"]
    D -->|是| R["选择复用或另存"]
    R -->|复用| X["使用现有文件"]
    R -->|另存| E
    E --> F["创建文件记录"]
    F --> G["进入解析队列"]
    G --> H["可用于知识库"]
~~~

### 7.1 导入前校验

校验：

- 扩展名；
- MIME 类型；
- 文件头或基础格式；
- 文件大小；
- 文件是否可读取；
- 文件名是否合法；
- 是否超过批量限制。

扩展名与实际格式明显不一致时拒绝导入。

### 7.2 复制

合格文件复制到应用管理目录。应用内部使用稳定 ID 和受控路径保存，不直接使用用户文件名作为唯一存储路径。

必须保留：

- 原始文件名；
- 显示名称；
- 扩展名；
- 大小；
- 内容哈希；
- 来源路径的脱敏信息或仅供本地显示的来源描述；
- 导入时间；
- 应用管理路径；
- 处理状态。

### 7.3 批量结果

一次导入多个文件时，结果按文件分别显示：

- 已成功加入处理队列；
- 已复用；
- 已另存；
- 类型不支持；
- 超过大小限制；
- 文件不可读取；
- 复制失败。

一个文件失败不能导致其他文件全部回滚。

## 8. 重复文件规则

### 8.1 精确重复

以文件内容哈希判断完全相同，不仅比较文件名。

检测到重复时展示：

- 当前文件名；
- 已存在文件名；
- 所属文件夹；
- 标签；
- 导入时间；
- 关联知识库；
- 两个选择。

### 8.2 复用现有文件

选择“复用”时：

- 不创建新的物理文件；
- 默认不创建重复文件记录；
- 打开现有文件或将现有文件用于当前知识库选择；
- 用户可以为现有文件补充标签；
- 不自动改变现有文件夹位置。

### 8.3 另存独立记录

选择“另存”时：

- 创建新的逻辑文件记录；
- 自动处理显示名称冲突，例如添加序号；
- 允许放入不同文件夹、添加不同标签；
- 物理存储可以复用同一内容对象，避免重复占用空间；
- 删除其中一个记录不能破坏另一个记录。

### 8.4 同名但内容不同

同名、同扩展名但哈希不同的文件不算重复。系统提示存在同名文件，并允许：

- 自动添加序号；
- 手动重命名；
- 取消该文件导入。

V1 不提供自动版本合并。

### 8.5 相似内容

内容相似但哈希不同的文件在 V1 不自动判定为重复。AI 相似内容检测列入后续版本。

## 9. 文件夹管理

### 9.1 基本规则

- 默认根目录为“全部文件”；
- 未指定目录的文件进入“未分类”；
- 最多 5 层；
- 同一父目录下文件夹名称不可重复；
- 一个文件同时只属于一个文件夹；
- 标签可以跨文件夹使用。

### 9.2 文件夹操作

支持：

- 新建；
- 重命名；
- 移动；
- 删除；
- 展开和折叠；
- 查看文件数量；
- 拖放文件到文件夹。

### 9.3 删除非空文件夹

删除时必须选择：

- 文件夹和内部文件一起进入回收站；或
- 仅删除文件夹，将内部文件移动到上一级。

系统不得默认删除内部文件。

### 9.4 移动

移动文件夹时：

- 不允许移动到自身或子目录；
- 不允许超过最大层级；
- 保留内部文件和子目录；
- 移动不触发重新解析或重新索引。

## 10. 标签管理

### 10.1 规则

- 一个文件最多 10 个标签；
- 标签名称去除首尾空格；
- 同名判断不区分大小写；
- 标签可设置颜色，但颜色不作为唯一识别方式；
- 标签不允许空名称；
- V1 不支持嵌套标签。

### 10.2 操作

支持：

- 创建标签；
- 给单个文件添加或移除标签；
- 批量添加或移除标签；
- 重命名标签；
- 删除标签；
- 按标签筛选。

删除标签仅解除关联，不删除文件，不进入回收站。

## 11. 文件列表

### 11.1 视图

V1 默认使用表格或高密度列表视图，不要求卡片视图。

字段至少包括：

- 复选框；
- 文件名；
- 类型；
- 文件夹；
- 标签；
- 大小；
- 处理状态；
- 关联知识库数量；
- 更新时间；
- 操作菜单。

### 11.2 搜索

文件页面内部搜索：

- 文件名；
- 标签；
- 摘要；
- 已解析正文。

### 11.3 筛选

支持按以下条件筛选：

- 文件夹；
- 标签；
- 文件类型；
- 处理状态；
- 是否已加入知识库；
- 导入时间。

### 11.4 排序

支持：

- 最近导入；
- 最近更新；
- 文件名；
- 文件大小；
- 文件类型。

### 11.5 列表状态保留

进入详情后返回，保留文件夹、搜索、筛选、排序、分页或滚动位置。

## 12. 批量操作

选择一个或多个文件后支持：

- 移动到文件夹；
- 添加标签；
- 移除标签；
- 加入知识库；
- 重新处理；
- 移入回收站。

批量操作要求：

- 显示已选数量；
- 操作前检查适用性；
- 分项显示成功和失败；
- 一个文件失败不阻止其他文件；
- 大批量解析和重建进入后台任务；
- 可取消的任务提供取消入口。

V1 不支持批量导出和文件内容批量编辑。

## 13. 文件详情

文件详情包含：

### 13.1 基本信息

- 显示名称；
- 原始文件名；
- 文件类型；
- 文件大小；
- 内容哈希的缩略展示；
- 导入时间；
- 最近更新时间；
- 文件夹；
- 标签。

### 13.2 处理信息

- 当前状态；
- 当前步骤；
- 解析结果；
- 页数、幻灯片数或文本长度；
- 切片数量；
- 索引状态；
- 最近处理时间；
- 错误原因；
- 重试入口。

### 13.3 摘要

- 文件解析成功后允许生成 AI 摘要；
- V1 默认按需生成，不在每次导入时自动产生外部模型费用；
- 已生成摘要本地保存；
- 文件内容发生变化或重新导入后摘要标记为待更新；
- 摘要失败不影响文件继续用于手动预览，但未完成必要索引时不能用于 RAG。

### 13.4 关联

展示文件所属的知识库，并支持：

- 加入知识库；
- 从知识库移除；
- 打开知识库；
- 基于文件提问；
- 基于文件开始学习。

### 13.5 操作

- 重命名显示名称；
- 移动；
- 编辑标签；
- 重新解析；
- 重建索引；
- 打开原文；
- 移入回收站。

## 14. 文件预览

### 14.1 PDF

- 显示 PDF 页面；
- 支持页码跳转；
- 从引用进入时定位到对应页；
- 解析文本可以与页面定位关联。

### 14.2 TXT 与 Markdown

- 文本只读预览；
- Markdown 以安全方式渲染；
- 支持标题或行号定位；
- 不执行内嵌脚本或不可信 HTML。

### 14.3 DOCX 与 PPTX

V1 不承诺完全还原 Office 排版。

- DOCX 展示提取后的结构化文本；
- PPTX 按幻灯片展示提取文本和编号；
- 用户可以通过系统默认程序打开应用管理副本；
- 引用定位到标题、段落或幻灯片编号。

## 15. 处理状态

文件状态至少包括：

| 状态 | 含义 |
| --- | --- |
| COPYING | 正在复制到应用目录 |
| QUEUED | 已进入处理队列 |
| PARSING | 正在解析文本 |
| PARSE_FAILED | 解析失败 |
| PARSED | 文本解析完成 |
| INDEXING | 正在切片、Embedding 或建立索引 |
| INDEX_FAILED | 索引失败 |
| READY | 可用于搜索、问答和学习 |
| NEEDS_REINDEX | 内容或索引规则变化，需要重建 |
| IN_TRASH | 已进入回收站 |
| PURGING | 正在永久删除 |

状态命名可在技术设计中调整，但语义必须完整覆盖。

## 16. 解析与索引流程

### 16.1 自动步骤

文件复制成功后：

1. 加入解析队列；
2. 解析正文和定位信息；
3. 保存结构化解析结果；
4. 建立本地全文搜索索引；
5. 根据知识库关联情况决定是否进入切片与向量索引。

没有加入任何知识库的文件也应完成解析和全文搜索，但是否立即生成 Embedding 在知识库与 RAG 文档中最终确定。

### 16.2 失败处理

失败时记录：

- 失败步骤；
- 用户可理解原因；
- 脱敏错误 ID；
- 是否可重试；
- 已完成步骤；
- 重试次数；
- 最近失败时间。

重试从安全且必要的步骤开始，不重复复制原文件。

### 16.3 取消

- 排队任务可以取消；
- 正在解析或索引的任务在安全点取消；
- 取消后文件记录和原文件副本保留；
- 用户可以稍后重新处理。

## 17. 文件与知识库关系

- 一个文件可以加入多个知识库；
- 一个知识库可以包含多个文件；
- 文件夹不会自动成为知识库；
- 将文件移动到其他文件夹不改变知识库关联；
- 修改标签不改变知识库关联；
- 文件进入回收站后立即从所有知识库的可检索范围排除，但关系保留以便恢复；
- 文件永久删除后，删除知识库关联、切片、Embedding 和向量索引；
- 文件恢复后检查原知识库是否仍存在，并检查索引是否需要重建。

## 18. 回收站行为

### 18.1 移入回收站

文件移入回收站后：

- 正常文件列表隐藏；
- 首页不再显示；
- 全局搜索排除；
- RAG 检索排除；
- 未开始的处理任务取消；
- 正在执行的处理任务尽快安全停止；
- 历史引用保留并标记来源在回收站。

### 18.2 恢复

- 恢复到原文件夹；
- 原文件夹不存在时进入“未分类”；
- 保留标签；
- 恢复知识库关系；
- 检查解析结果和索引有效性；
- 必要时进入 NEEDS_REINDEX。

### 18.3 永久删除

永久删除：

- 文件记录；
- 应用管理的文件副本或对应物理内容引用；
- 解析正文；
- 全文索引；
- 切片；
- Embedding；
- 向量索引；
- 知识库关联。

如果多个逻辑文件记录复用同一物理内容，只有最后一个引用永久删除后才能删除物理内容。

对话和学习历史保留，但引用标记为来源已永久删除。

## 19. 安全要求

- 不信任扩展名，必须检查实际格式；
- 文件名不得直接拼接为物理存储路径；
- 防止路径穿越；
- Office 和 Markdown 预览不执行宏、脚本或不可信 HTML；
- 不自动访问文档中的远程资源；
- 解析进程需要限制资源和执行时间；
- 错误日志不得记录整份文件正文；
- 原始文件默认不发送给外部 AI Provider；
- 只有明确的摘要、问答或学习任务才发送必要文本片段。

## 20. 空状态与异常

### 文件列表为空

显示支持格式和“导入文件”按钮。

### 当前文件夹为空

显示“导入文件”和“移动已有文件到这里”。

### 搜索无结果

显示当前条件，并允许清除搜索和筛选。

### 存储空间不足

- 导入前尽量检测；
- 停止复制；
- 不创建不完整文件记录；
- 告知所需空间和可清理内容；
- 已有数据不得受损。

### 应用管理文件丢失

- 文件状态标记为异常；
- 不伪装为 READY；
- 提供查看详情、从来源重新导入或永久清理记录；
- 不自动读取来源路径恢复。

## 21. 验收标准

### FILE-AC-01

用户可以一次导入多个 PDF、DOCX、PPTX、TXT 和 Markdown 文件。

### FILE-AC-02

导入完成后移动或删除来源文件，不影响应用内文件。

### FILE-AC-03

不支持的文件格式和超过 50 MB 的文件在复制前被拒绝，并显示原因。

### FILE-AC-04

完全相同的文件通过内容哈希被识别，用户可以复用或另存。

### FILE-AC-05

同名但内容不同的文件不会被误判为完全重复。

### FILE-AC-06

用户可以创建最多 5 层文件夹，并移动文件和文件夹。

### FILE-AC-07

用户可以给文件添加最多 10 个标签，并按标签筛选。

### FILE-AC-08

用户可以批量移动、添加标签、加入知识库、重新处理和删除文件。

### FILE-AC-09

文件解析和索引过程显示状态；失败时显示步骤、原因和重试入口。

### FILE-AC-10

PDF 引用可以定位页码，PPTX 引用可以定位幻灯片编号。

### FILE-AC-11

扫描 PDF 无文本时不会被错误标记为解析成功。

### FILE-AC-12

文件摘要按需生成，导入文件不会自动产生外部模型费用。

### FILE-AC-13

文件进入回收站后立即从正常搜索和 RAG 中排除，并可在 30 天内恢复。

### FILE-AC-14

文件永久删除后，对应切片、Embedding 和向量索引被清理。

### FILE-AC-15

多个逻辑文件复用相同物理内容时，删除一个记录不会损坏另一个记录。

## 22. 本部分冻结结论

- V1 支持 PDF、DOCX、PPTX、TXT 和 Markdown；
- 不支持 OCR、表格文件、网页抓取、音视频和压缩包；
- 文件导入后复制到应用管理目录；
- 单文件默认限制 50 MB，单次最多 20 个文件和 500 MB；
- 文件夹最多 5 层，一个文件属于一个文件夹；
- 一个文件最多 10 个标签；
- 精确重复使用内容哈希判断；
- 用户可以复用已有文件或另存独立记录；
- 相似内容检测不进入 V1；
- 文件摘要按需生成；
- 一个文件可以加入多个知识库；
- 文件进入回收站后立即停止参与搜索和 RAG；
- 文件永久删除时清理解析、索引和向量数据；
- Office 预览以结构化文本为主，不承诺完整还原排版。
