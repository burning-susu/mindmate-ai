## 5. 导航和返回规则

- 一级导航只包含五个页面壳；不生成设置、错题本、管理后台和云同步入口。
- 知识库列表进入知识库详情，文件列表进入文件详情；详情返回父列表并尽量保留搜索、筛选、排序和滚动位置。
- 引用进入文件详情后，返回动作回到原 AI 消息并保留引用上下文；具体 URL 和 History 策略为 TBD。
- 文件详情启动问答或陪练时进入 AI 对话并携带文件范围，不新增一级页面。
- 三种 AI 模式属于同一对话页；切换资料问答必须选择知识库，切换知识库要提示上下文影响。
- 刷新后最低要求是恢复当前页面、资源/会话标识和可查询的异步状态。
- 深链接、正式 URL、路由字符串和资源不存在时的具体路由处理为 TBD。

## 7. 关键 UI 流程

### FLOW-UI-001 文件导入到可检索

入口：UI-KB-DETAIL-001。选择文件 → 校验 → 上传中 → 解析中 → 摘要/标签 → 索引中 → 可使用。失败保留原因和重试，原文件不静默删除。关联 REQ-FILE、REQ-TASK、AC-002/003/010/011/021。

### FLOW-UI-002 资料问答和引用

选择知识库/文件 → 输入问题 → 生成中 → 回答 → 展开引用 → 文件详情。证据不足拒答；Provider 失败保留输入并重试；文件删除后引用显示失效。关联 REQ-CHAT-008、REQ-CITE、AC-004/005/012/013。

### FLOW-UI-003 自由对话

新建会话 → 输入消息 → 生成中 → 完成/停止/失败 → 复制或重试。自由对话不自动读取知识库。关联 REQ-CHAT-001~007、AC-004/012。

### FLOW-UI-004 学习陪练

配置范围/主题/难度/题量 → 出一题 → 用户作答 → 点评 → 继续/追问/重试/结束。资料不足和 Provider 失败均可恢复。关联 REQ-PRACTICE、AC-006~008。

### FLOW-UI-005 历史会话恢复

首页最近会话或历史页 → 搜索/打开 → 恢复消息、模式和范围 → 继续对话/陪练。部分恢复显示状态，会话不存在返回列表。关联 REQ-HISTORY、AC-009。

### FLOW-UI-006 删除资源

删除 → 展示影响 → 用户确认 → 清理片段/索引 → 历史引用失效。取消确认不改变资源。关联 REQ-KB-005、REQ-FILE-010、REQ-CITE-005、AC-013。

### FLOW-UI-007 本地导出/备份和恢复

候选入口：UI-BACKUP-001，挂载位置 TBD，不新增设置一级页面。导出：选择导出 → 敏感数据警告 → 选择本地位置 → 处理中 → 成功/失败。恢复：选择备份 → 校验 → 覆盖/合并警告 → 确认 → 进度 → 完成/部分失败。格式、内容、加密、索引和回滚由 G6/G8/G10 定义。关联 DEC-G5-001、REQ-PRIVACY、TBD-PRD-006。
