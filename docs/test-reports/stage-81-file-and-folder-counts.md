# 第八十一批：文件与目录计数修复

- 日期：2026-10-10
- 现象：移入回收站后，“面试题”目录仍显示旧数量；选择该目录时，“全部文件”显示的却是当前目录筛选结果。

## 根因与修复

- 后端目录 payload 已按 `deleted_at IS NULL` 统计活动文件。前端单文件移入回收站成功后只刷新了 `files`，未刷新 `folders`，所以目录计数仍是旧缓存。
- “全部文件”目录行原先使用当前筛选后的 `files.length`。新增复用现有 `/api/v1/home/overview` 查询，展示全局未回收文件数；该数量不随目录、类型、标签和搜索筛选改变。
- 文件上传/重复决策、文件软删除、目录递归删除和批量文件操作成功后刷新文件夹计数和全局概览。
