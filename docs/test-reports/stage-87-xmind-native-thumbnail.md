# 第八十七批：XMind 原版式预览

- 日期：2026-10-10
- 目标：显示 XMind 文件原有的布局、连线和主题视觉效果，避免仅按提取文本重绘。
- 实现：发现示例 XMind 包包含 `Thumbnails/thumbnail.png`（1794×732）。后端新增只读 PNG 响应接口，从托管包内存读取固定条目，不落盘；前端优先展示原版式图，并提供原尺寸查看。缺少或无效缩略图时自动回退到主题树。
- 安全：最多读取 8 MiB；校验 PNG 签名、IHDR、最大像素数和压缩比；不读取其他附件，不新增依赖。
