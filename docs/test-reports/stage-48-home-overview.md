## 计数口径

`GET /api/v1/home/overview` 在同一次 SQLite 读事务里统计。页面和接口使用同一段 `count_scope` 文案。

- 文件：`deleted_at IS NULL`，包含解析失败和其他未进回收站的状态。
- 知识库：`deleted_at IS NULL`，包含空库、准备中和索引失败。
- 对话：`deleted_at IS NULL`，包含普通对话和知识库对话。
- 学习会话：`deleted_at IS NULL`，包含未完成、已完成和未能出题。
- 回收对象不计入。查询失败时页面保留上次成功数字，或显示“概览暂时读不出来，不能把失败显示成 0。”，不把失败显示成 0。
- 点击数字只导航：文件到 `/files`，知识库到 `/knowledge-bases`，对话到 `/history`，学习会话到 `/history?tab=learning`。

## 任务口径

- 排队：`CREATED` 与 `QUEUED`。
- 运行：`RUNNING`。
- 失败：`FAILED`。
- `BLOCKED`、`INTERRUPTED` 单独计数，大于 0 才展示。
- 只有检查点能证明已有工作量时，运行中任务才显示 0–100 的百分比。排队时的 0 和没有工作量证据的 100 不显示成百分比。
- 失败只返回安全错误码。摘要含路径、密钥、堆栈或过长文本时显示“失败详情已省略”。响应不带检查点、路径或原始堆栈。
- 无任务时首页只留“查看后台任务”，不占摘要区。面板列出最近任务，可看同一安全投影的详情，没有取消或重试按钮。
- 仅当排队或运行大于 0 时，首页每 4 秒重读一次同一概览。读取不创建任务。页面卸载后停止观察。
