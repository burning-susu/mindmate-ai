# 第八十三批：多格式文件阅读预览

- 日期：2026-10-10
- 用户目标：不仅 Markdown 使用阅读排版，其他支持格式也按格式提供合适的详情预览。

## 格式行为

- PDF：嵌入本地受控的原文件内容地址，由浏览器 PDF 阅读器保留原页版式、缩放和分页。无可抽取文字的扫描 PDF 仍展示原页面，并提示 OCR 不支持；若有提取文字，可展开查看。
- DOCX：将现有解析结果排成阅读页，按段落展示，并把解析器输出的制表符行展示为表格。
- PPTX：按提取顺序展示文本块并显示真实幻灯片数；明确说明这是提取文本，原始幻灯片版面请用“打开原文”。不把文本块伪造成幻灯片缩略图。
- TXT：使用比例字体和段落阅读样式，保留源换行。
- Markdown：沿用第八十二批标题、强调、列表、引用、表格、代码块阅读渲染。

## 安全与边界

- PDF 内容只从应用已有的本地受控文件 API 加载。
- DOCX/PPTX/TXT/Markdown 都只以 React 文本节点渲染，不把解析文本当作 HTML 执行。
- 未新增依赖、API 契约、数据库结构或解析任务；没有调用外部转换服务。
- DOCX/PPTX 当前提供结构化文本阅读，不是原文件像素级排版还原。要获得完整 Word 页面或 PowerPoint 幻灯片视觉，需要本地转换/渲染运行时并进入依赖和打包评审。
