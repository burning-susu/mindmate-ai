# 第八十六批：XMind 主题树布局优化

- 日期：2026-10-10
- 现象：首版预览将 XMind 全部主题按单列从上到下排列，中心主题、一级分支与子主题的空间关系不明显，长图需要连续向下滚动。
- 修复：以根主题为中心；一级分支按源顺序交错布局在左右两栏；各分支子主题嵌套在对应分支下；增加中心连接线和分支脊线、轻量画布网格、横纵滚动。工作表和长主题可在独立画布内查看。
- 文案：将容易把根主题算入的“分支数量”改为“主题节点数量”。
