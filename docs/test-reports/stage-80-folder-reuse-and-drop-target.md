# 第八十批：文件夹内重复复用与工作区拖放导入

- 日期：2026-10-10
- 范围：文件页在文件夹筛选时的重复复用归档行为，以及拖放导入命中区域。

## 修复

- 用户在指定文件夹中上传重复文件并选择“复用现有”时，后端将复用的活动或恢复 FileRecord 移入该目标文件夹，并按该文件夹范围生成不冲突的显示名称。未指定目标文件夹时保持原有目录。
- 复用成功后失效文件和文件夹查询缓存，目录文件数与列表同步更新。
- 将拖拽事件从 56px 虚线提示框提升到整个右侧文件工作区。拖入文件时显示覆盖工作区的“释放文件以导入”提示，拖放到工作区内任意位置都会提交原有导入流程。
