## 排序依据

- 最近知识库：没有最近使用时间。`GET /api/v1/knowledge-bases` 增加可选 `limit`，按 `updated_at` 降序、同时间再按知识库 ID 降序，并排除 `deleted_at` 非空的记录。首页请求 `limit=4`，时间标签是“最近更新”。
- 最近文件：没有最近打开时间。复用 `GET /api/v1/files?sort=updated_at&limit=5`，默认排除回收文件。时间标签是“最近更新”。
- 最近对话：复用 `GET /api/v1/history/conversations?limit=5`。该接口按 `last_active_at` 排序，响应里的 `updated_at` 就是这个活动时间。时间标签是“最近活动”。列表排除已回收对话，查询本身不提交来源状态。

## 展示与去向

- 知识库卡片显示名称、已有简述或“暂无简述”、活动成员文件数量、索引状态和最近更新。卡片进入原详情，“查看全部”进入 `/knowledge-bases`。只有 `READY` 且可用文件数大于 0 时才显示“开始学习”“提问”，分别进入已有 `/learning/new` 和 `/chat` 并带上知识库 ID。失败、空库或没有可用文件时标明不能直接学习或提问，并给出“查看知识库”。
- 文件卡片显示文件名、类型、文件夹或“未分类”、标签或“无标签”、处理状态和最近更新。解析失败带上已有的失败阶段和错误 ID。点击进入原文件详情，“查看全部”进入 `/files`。重试先出现“确认重试”，确认后才调用已有重新处理接口。
- 对话卡片显示原标题、已有摘要、普通对话或知识库名称，以及最近活动。点击进入原 `/chat/:id`，不发送新消息。“查看全部”进入 `/history` 的对话标签。来源失效时提示原因，仍然只打开原对话。

某一栏读取失败时只在该栏显示重新加载，其它栏和继续学习、快捷操作继续显示。
