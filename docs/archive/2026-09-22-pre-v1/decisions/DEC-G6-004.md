## 1. 即时应用来源

用户在当前轮一次明确回复以下 4 项选择：

```text
TECH-G6-CHAT-MODEL=A
TECH-G6-EMBEDDING=A
COST-G6-PROVIDER=A
TECH-G6-VECTOR-STORE=A
```

按照 `V3.2_IMMEDIATE_APPLY`，上述选择在同一轮构成确认和应用授权，并已完成内部 `DECISION_APPLY`。本轮不要求二次确认，不要求用户发送 `DECISION_APPLY`，不调用 Provider，不读取或验证 API Key，不下载或安装 Embedding 模型。

## 2. 批量应用结果

### 2.1 `TECH-G6-CHAT-MODEL=A`

- 当前 Chat Model：`deepseek-flash`。
- 官方映射：DeepSeek-V4.1-Flash。
- 适用范围：自由问答、资料问答、学习陪练、总结和 RAG 结果生成。
- 当前状态：`APPLIED_CONDITIONAL`；账号、模型权限、地区、API 条款和 Provider runtime 仍未通过。
- 本轮没有调用模型，也没有把该选择解释为已完成真实集成或质量验收。

### 2.2 `TECH-G6-EMBEDDING=A`

- Embedding 方向：本地 `BAAI/bge-small-zh-v1.5`。
- 数据边界：知识库切片生成 Embedding 的过程不发送给外部 Embedding Provider。
- 当前状态：`APPLIED_CONDITIONAL / SPIKE_REQUIRED`。
- 本轮不下载、不安装、不运行模型；CPU/GPU、内存、速度、中文检索质量、许可证核验和升级/重建成本留后续 Spike。
- DeepSeek API 不被推断为 Embedding Provider。

### 2.3 `COST-G6-PROVIDER=A`

- 月软预算：USD 5。
- USD 4：提醒阈值。
- USD 5：停止新 Provider 请求。
- 禁止自动充值、自动提额和自动绕过停止策略。
- 达到停止阈值后必须由用户手动恢复；预算不足、认证失败和限流不做无限重试。
- 当前状态：`APPLIED_POLICY / IMPLEMENTATION_PENDING`。本轮没有真实计费、余额查询或运行时成本阻断实现。

### 2.4 `TECH-G6-VECTOR-STORE=A`

- 向量存储方向：本地嵌入式向量存储，通过 `Storage Adapter` 与业务模块隔离。
- 原始文件、解析文本、Embedding 和索引默认留在用户设备。
- 当前状态：`APPLIED_DIRECTIONAL / PRODUCT_SPIKE_REQUIRED`。
- 具体产品/类别、物理共置、索引格式、重建、升级和失败恢复规则留 G8 Spike 与详细技术设计。
- 不创建本地数据库、向量库、依赖或代码。

## 4. 门禁与回退

- DeepSeek API 数据处理、保留/训练、删除、地域、账号、模型权限和余额 Guard 未全部通过，继续保持 `OPEN-01`。
- Provider Runtime 继续禁用；本批决策不授权真实 API、文件上传、Key 读取或 Embedding 运行。
- 任何 Guard 失败时回退到 DEC-G6-001 no-call；不自动切换 Alibaba 或其它 Provider。
- Embedding 本地 Spike、向量存储产品 Spike、成本计数/停止实现和 Chat 质量验收完成后，重新执行 G6 Exit Preflight。
