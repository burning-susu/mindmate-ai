## 决策背景

Approved PRD 和 DEC-BOOTSTRAP-001 已确认对话模型与 Embedding 使用外部 Provider，并经本地后端 Adapter 连接；外发范围遵循当前任务最小必要原则。Provider、模型/Embedding、处理地域、数据处理/保留条款和成本边界仍未确认。G6 Exit 需要解决这些事项，因为它们决定本地资料片段和会话上下文会发给谁、在哪里处理和按何种条件保留。

用户已完成 TECH-DEC-004 的影响复述后初选 C、二次确认，并使用“应用并同步 TECH-DEC-004=C”明确授权应用。该选择只确认 Provider 细节未决期间的临时出站策略，不是 Provider/模型选型，也不覆盖原有 EXTERNAL_PROVIDER 方向。

## 已应用决策

- 在具体 Provider、模型、Embedding、地域、数据处理/保留条款及成本边界完成核验和确认前，不发起真实模型或 Embedding 外部请求。
- 保留本地 Provider Adapter 和供应商无关架构边界；不写入具体供应商、模型 ID、地域、价格、账号或 Key。
- 原始文件、业务数据、解析结果和向量数据默认继续保存在本地；不引入远程业务服务器、云同步、远程备份或跨设备同步。
- 未来外部调用仍限于完成用户当前操作所必需的问题、文本片段和上下文；不得默认上传完整原始文件或全部会话历史。
- 这项临时边界已应用，但 OPEN-01 的 Provider/模型/Embedding/地域/条款/成本事项仍未关闭；G6 保持 BLOCKED，G7 入口保持 NOT_READY。

## 影响

- 文件可在本地保存和执行不依赖外部服务的解析；需要 Embedding 的索引阶段在 Provider 未配置时不能完成，也不得报告可检索成功。
- 自由对话、资料问答和学习陪练在没有经确认 Provider 的情况下不能执行真实模型生成；需由后续 G8/G9 设计明确的未配置和失败状态。
- 暂不发生外部 Provider 调用或相关调用费用；本地数据出站风险降低，但 AI 核心链路不能完成真实集成、延迟、成本或质量验收。
- 后续选择 Embedding 服务时，讲义/文件切片可能离开本地；必须先核验服务条款、处理地域、留存/训练条件及成本，并在用户确认后再开启调用。
- 不改变 Approved PRD 的外部 Provider 方向，不替代用户对具体 Provider 的后续决策，不等于 G6 完成或获得代码/集成权限。

## 未决事项与重评触发

以下事项仍归 OPEN-01 / TECH-DEC-004 管理：Provider 名称、对话模型、Embedding 模型、地域、数据处理与留存条款、训练用途、可用性和成本上限。获得具体候选及可核验证据后，重开 TECH-DEC-004 执行方案评审、二次确认和受控应用；在此之前继续执行本决策的 no-call 边界。
