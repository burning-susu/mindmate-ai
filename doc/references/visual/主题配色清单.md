> 文档版本：V1.1

## 0. 本文档定位
本文档是**可复用的配色资源库**，汇总五大主流场景的标准化配色方案，每套包含主色、辅助色、文字色、背景色、功能色，附带 HEX 色值和技术栈无关的 Design Token 代码，可直接筛选复用。

本文档不假定使用任何具体前端框架或 CSS 方案。若某项目选定使用 Tailwind，如何把本文档的色值接入 `tailwind.config` 见 `CSS方案选型与Tailwind规范.md`；若使用其他方案（原生 CSS、CSS-in-JS、其他 UI 框架的主题系统等），直接复用下方第8节的 CSS 自定义属性即可。

具体某个项目/REQ 选定用哪一套配色，属于该项目的技术决策，应写进对应 REQ 的 `spec.md` 或项目自己的技术文档里注明"选用了本清单第几类第几套方案"，本文档本身不绑定任何具体项目。

参考来源：Adobe Color、Coolors、ColorHexa、中国传统色、Color Hunter。所有配色遵循 WCAG 无障碍可读性规范，无高饱和荧光色、无杂乱撞色，适配 PC 端优先、移动端自适应。

## 1. 军事/政务/国企门户配色（庄重权威、低饱和稳重）
核心风格：严肃、正式、公信力强、低对比、无花哨动效。

### 方案1：经典政务深蓝（通用首选）
- 主色 `#005EB8`（导航、标题栏、核心按钮）
- 辅助色 `#003366`（模块边框、高亮标签）
- 强调色 `#E63946`（低饱和红，仅用于通知、紧急提示）
- 正文文字 `#333333` / 次级文字 `#666666`
- 背景 `#F5F7FA`（页面）/ `#FFFFFF`（卡片）
- 分割线 `#E2E2E2`
- 适配场景：通用政务门户、军事资讯门户、国企官网、党政公示网站

### 方案2：沉稳藏青极简风（高端正式）
- 主色 `#0A2C5B`，辅助色 `#194075`，强调色 `#2E86AB`
- 正文文字 `#2D3748` / 次级文字 `#718096`
- 背景 `#F8FAFC` / `#FFFFFF`，分割线 `#CBD5E0`
- 适配场景：军事科研、国防科技、高端政务公示、涉密类展示门户

### 方案3：国风沉稳灰蓝（中式政务）
- 主色 `#1D3A5F`，辅助色 `#4B4C4D`，强调色 `#C81623`（正统中国红）
- 正文文字 `#333333` / 次级文字 `#A9A8A7`
- 背景 `#F5F5F5` / `#FFFFFF`，分割线 `#E5E5E5`
- 适配场景：党政文化、国防宣传、国风政务门户网站

## 3. 科技/软件/SaaS 官网配色（清爽未来）
核心风格：低饱和冷色调、通透清爽、科技感强。

### 方案1：深空科技蓝
- 主色 `#0F1A2D`（深空底色），辅助色 `#00BFFF`，强调色 `#00E5CC`
- 正文文字 `#E8F4F8`（深色背景配浅文字）/ 次级文字 `#A0B4C8`
- 背景 `#0A101F` / `#FFFFFF`（深浅双模式）

### 方案2：极简清透科技色
- 主色 `#2563EB`，辅助色 `#60A5FA`，强调色 `#10B981`
- 正文文字 `#1F2937` / 次级文字 `#6B7280`
- 背景 `#F0F7FF` / `#FFFFFF`

### 方案3：亮色科技蓝（文娱/传媒科技门户，真实项目实测值）
> 来源：文娱门户网站定版源码实测（`桌面/文娱类资料整理/website`，2026-09-07），配色从视觉参考站相芯科技提取而来，非自选。适用于文娱、传媒、数字内容类偏应用的技术门户——既要科技感，又不能像前两套那样冷峻。

- 主色 `#0087F7`，浅主色 `#00BCFC`，深主色 `#0068C8`，主色浅底 `#E9F4FF`
- 品牌渐变 `linear-gradient(231deg, #00BCFC 0%, #0087F7 100%)`（**231deg 是该参考站的特征角度，成套使用才有辨识度**）
- 正文文字 `#1B1B1B` / 板块标题 `#323335` / 副标题 `#777777` / 弱化文字 `#9AA2B0` / 导航文字 `#141414`
- 背景 `#FFFFFF` / 次级 `#F6F8FB` / 三级 `#EEF2F7`，边框 `#E8ECF2`
- 阴影 `0 14px 40px rgba(20,50,110,.1)`（大）/ `0 6px 20px rgba(20,50,110,.07)`（小）
- **圆角 6px**（偏小，是这套风格的关键特征，放大到 12px 以上就不像了）

**这套方案回答了一个真实决策**：该项目最初被指"主题色彩过于暗淡"，要求"设计一个鲜艳明亮一点的颜色"。最终不是靠自己调色解决的，而是整站转向单参考同源模式后，**直接采用参考站的配色体系**才收敛。经验：配色诉求以形容词形式出现时（"鲜艳明亮一点"），比自己试色更快的路径是找一个视觉标杆站整套提取。

## 6. 通用功能色（全场景通用，固定不变）
- 成功色 `#00B42A`（提交成功、完成状态）
- 警告色 `#FF7D00`（提醒、待处理状态）
- 危险色 `#F53F3F`（删除、报错、紧急提示）
- 禁用色 `#C9CDD4`（禁用按钮、不可操作元素）
- 遮罩色 `rgba(0,0,0,0.5)`（弹窗背景遮罩）

## 7. 落地使用规则
1. 项目初始化时，仅选择一套对应场景的主题配色，禁止多套混用
2. 全局功能色固定不变，所有页面、组件、交互状态统一复用
3. 开发、AI 生成、MCP 解析设计稿时，直接引用下方第8节里的 `primary/secondary/accent/text/bg/border` 命名的色值变量，禁止在组件里手写固定色值
4. 适配本手册 `设计稿转代码流程.md` 里的所有路线（AI 直出、低保真 MCP、高保真 MCP）
5. 本清单只定义色值和变量命名，不绑定任何具体 CSS 方案。项目实际接入方式（Tailwind config、CSS 自定义属性、Sass 变量、styled-components 主题对象等）由项目自己的技术栈决定

## 8. 配色变量定义（技术栈无关，直接落地）
以下用 CSS 自定义属性（`:root` 变量）表示每套方案的色值映射，可原样使用，也可按项目实际技术栈转换成对应格式（如 Tailwind 的 `colors` 配置、Sass 的 `$variable`）。核心规则：一个项目仅保留一套主题配色，功能色永久全局启用。

### 8.1 全局通用功能色（所有项目必加）
```css
:root {
  --color-success: #00B42A;
  --color-warning: #FF7D00;
  --color-danger: #F53F3F;
  --color-disabled: #C9CDD4;
  --color-mask: rgba(0,0,0,0.5);
}
```
