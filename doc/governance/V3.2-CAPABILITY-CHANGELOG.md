## 激活与事实源边界

Capability 文档只负责“判断、方法和执行知识”。具体项目采用哪一种方案、使用什么框架/Provider、目标阈值是多少，应由项目 `PROJECT_PROFILE` / `ASSESSMENT` / `Spec` / `ADR` 确认。

`AGENTS.md`、编辑器规则或 Prompt 不得复制维护一套与 Capability 不同的正式内容；编辑器规则只能作为运行时适配层。
