# V3.2-GENERIC-MAP

## 目的
本文件说明旧文档如何进入 v3.2 通用资产体系，以及为什么不是简单删减。

## 核心原则

> **通用化 = 保留能力细节 + 去掉项目事实 + 参数化项目差异 + 接入 v3.2 生命周期。**

因此 Capability 文档默认不做“摘要化”。原文中的判断标准、步骤、示例、反模式、检查项、验收条件能保留的都保留。

## 不作为通用 Capability 的文件
- 项目源码事实验证规则；
- 项目具体目录/模块/服务地址；
- 特定公司、站点或品牌的视觉提取结果；
- 已确定技术栈的项目实例规则。

这些内容应进入项目实例层、references 或项目专属 rules。
