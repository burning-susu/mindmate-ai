# 执行校准清单
> 文档版本：V3.2-GENERIC
> 定位：执行中 / 收尾自检

> 启动路由以根目录 `AGENTS.md` 为准；本文不重复定义完整启动流程。

## 1. 开始执行前

- [ ] 当前任务属于哪个 REQ / Change / Bug / Review？
- [ ] 当前事实源是哪一份？
- [ ] 当前 Workflow / Stage 是否明确？
- [ ] 本任务需要哪些 Capability？
- [ ] 需要激活哪些 Rule？
- [ ] 是否存在未解决的冲突 / TBD？
- [ ] 是否存在高影响决策？

## 2. 执行中

- [ ] 是否越出 Scope？
- [ ] 是否创造了新的事实源？
- [ ] 是否重复实现已有能力？
- [ ] 是否引入未声明依赖？
- [ ] 是否存在安全或数据风险？
- [ ] 测试场景是否覆盖正常、边界、异常和关键流程？
- [ ] UI / API / Data 变更是否仍与当前契约一致？

## 3. 收尾

- [ ] 代码状态已记录；
- [ ] 测试状态已记录；
- [ ] 验收状态已记录；
- [ ] Merge / Release 状态已记录；
- [ ] Evidence 已留存；
- [ ] Trace 已更新；
- [ ] 变更影响面已闭合；
- [ ] 若出现新稳定规则，已判断是否应沉淀到 `doc/rules` 或 `doc/capabilities`。

## 4. 不应沉淀的内容

- 单项目临时决定；
- 一次性 workaround；
- 未验证推断；
- 真实凭据与敏感数据；
- 只对某个目录结构成立的规则。
